01 / THE APPROACH

从一个物件，展开一场研究。

从主体的轮廓、构造与材料找到观看问题。研究媒介、空间和光色共同决定它怎样被发现，按本次任务选择机位与表达。

01

先看懂物件

识别主体的实际部件、结构和比例，再决定实物、模型或图稿的呈现方式。

02

让材料回应光线

线圈、刻痕、压印与透明层各自形成图形；材料、构图和光共同支持本次观看问题。

03

组织完整的构图

主体、图稿和样片各有位置与用途。用分组、间距和留白建立清楚的观看顺序。

02 / SELECTED STUDIES

同一主题，两种画幅。

九组案例分别设计横幅与竖幅。切换画幅，观察物件、纸层和留白怎样重新组织。点击图片查看原图。

03 / LIGHT & COMPOSITION

为主题选择合适的光线。

选择当前研究的媒介和观看方式。下方是常用起点，更多方法见 视觉语言、研究媒介与材料形成。

Transmitted light

底光透射

明亮光台、深色实体，以及薄纸和色片的透射密度。

Diffused paper

柔光纸层

乳白扩散面、轻柔纸纹，以及被覆盖后变淡的笔迹。

Color field

色场主视觉

用集中的主体、明确的色场与有限的搭配形成重点。

At work

工作台动作

描绘、摆放或手持图稿，让工具与实际操作相接。

Material detail

材质近摄

靠近表面，观察金属反射、纸张纤维和工艺细节。

04 / GET STARTED

把主体交给它。
从一句话开始。

适用于具备图片查看与图像生成工具的 Codex 环境。编译脚本使用 Python 3.10 及以上版本的标准库。

完整使用说明 ↗配图来源 ↗

01解压并安装

将安装包解压，进入 siuyu-lightbox-still-life 文件夹，运行：

python3 scripts/validate_skill.py .
python3 scripts/install_skill.py

默认装入 ~/.codex/skills/siuyu-lightbox-still-life。安装后重新加载 Skills 或重新打开 Codex。

02附上主体或参考，发送请求

可以从产品照片、物件参考或一个文字概念开始。AI 记录来源用途与画面关系，再按同一方向执行并看图。

选中后按 ⌘C 或 Ctrl+C 复制

03查看图片，继续细化

图像生成后，检查实际结构、构图与材料关系。你可以继续指定光线、搭配或局部细节，也可以为同一主体设计竖幅。

05 / GOOD TO KNOW

开始前的几个细节。

只有文字想法，可以生成吗？

可以。描述主体、画幅和想研究的特征即可。具体主体照片用于确定身份；风格参考按光线、颜色或布局的用途参与设计。

图片和案例是否随包提供？

包内有九组十八张横竖案例，以及一张底光硫酸纸展示图。每张图都保留来源与生成说明，解压后可以本地浏览。

还能指定其他画幅与精确尺寸吗？

可以指定目标画幅和尺寸，交付时核对图像工具返回的实际像素。当前横竖案例的原生尺寸为 1672×941 和 941×1672，与 16:9、9:16 存在整数取整差。

怎样更新已安装的同名版本？

在新包目录运行 python3 scripts/install_skill.py --backup-existing。此前版本完整保存在 Skills 目录旁的 skill-backups/，脚本输出实际保存位置。

这个 Skill 提供哪些能力？

它提供主体判断、美术与摄影指导、自然语言方向执行和结果检查流程，也支持纸面照片与织物印花。图像生成由运行环境中的工具完成；需要本地确定性渲染时，另行准备配套工程，参见 离线工作流。
