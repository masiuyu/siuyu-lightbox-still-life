# 扣件与织带：穿行结构说明

## 参考图片

本例沿用材料摄影方向的设计设定：圆角矩形扣件，中间一道横杆，织带穿过两侧长孔并沿横杆折返。

## 成像说明

一张横向 3:2 的平面装配说明图，以清楚的轴测视图表现圆角矩形扣件和织带的穿行。扣件位于画面中央偏左，中央横杆和两侧长孔清晰可读。织带从左下方进入一个孔，绕过中央横杆，再从另一孔向右上方折返；同一条带的边缘在每处遮挡前后连续对应。
采用白色基底和一种深绿色印色。扣件主要由清楚的轮廓线与必要结构线表达，织带用连续宽带形及少量方向线表达。叠压处以轮廓中断和露出的白色间隔说明上下关系，近处结构线具有较高视觉权重。两枚简洁箭头顺着织带的实际走向安排，帮助观者先理解进入、绕行与离开的次序。
右侧留出与结构图相连的宽松空区，整体层次由几何形状、遮挡和线条密度形成。图面准确文字只有右下方小标题“织带折返”，保持结构关系为第一阅读内容。

## 工作记录

本例与材料摄影使用同一设计设定，改变观看目的、投影及信息表达。核心观察是穿行拓扑和遮挡连续性；图像生成与结构清晰度等待实际图片。
