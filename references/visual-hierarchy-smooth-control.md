# 视觉层级与 Smooth Control

用于写成像说明、选择材料尺度和评审实际图片。默认先建立清楚的大形、大关系与连贯色调，让必要纹理支持当前主视觉任务。这里的平滑指画面组织、色调过渡和信息密度；真实物件与环境继续保有各自的物理线索。

## 默认按观看顺序写方向

先选一个主视觉目标：本张首先让观者辨认什么、发现什么，或理解哪种关系。多个物件、材料和准确文字都可以参与这项任务，其优先级和面积由同一目标组织。局部修改以用户指定的改变为目标，保持项继续作为边界。

成像说明按下面的依赖展开，具体写成自然段：

1. **主体层级。** 主体是谁，辅助内容怎样支持它，当前必须保留哪些身份。
2. **构图关系。** 大体量、占比、位置、朝向、空间分区、留白及必要接触；画幅和机位支持这些关系。
3. **关键光色与材质。** 主要光面和暗面怎样解释体积，色块怎样形成主次，各材料通过什么必要响应区别。
4. **少量必要细节。** 最后补充直接影响识别、工艺、连接、准确文字或叙事的局部，安排合适的观看面积。

关键轮廓和大块面先形成阅读，再按任务展开细节。一个主视觉目标可以结合多种技法，但各自强度要相容，尤其是焦点、动静、颗粒、装饰及表面尺度。提示词长度由任务决定，细节是否有用由它改变的可见判断决定。

默认把清楚、统一的组织直接写进已选画面。例如：“大块明暗过渡连贯，主体轮廓与空间分区清楚，背景和辅助物保持安静；必要纹理按材料、光和观看距离自然出现。”按当前对象改写这句话，使它属于本图。默认规则在 AI 写方向时落实，编译脚本逐字传递最终采用的成像说明；调用前连读实际提示词核对。

## 给纹理具体位置和作用

先决定本张依赖哪项材料线索：轮廓与倒角、反射形状、色差、厚度、交织、孔隙或接缝。再决定该线索在哪片表面、占多大面积、在当前观看尺度怎样出现。细腻表面可以主要由连续反射和柔和过渡说明，必要近景再展开细节；微距研究则把指定结构作为主要尺度。

| 当前对象 | 应保留的必要线索 | 清楚的组织怎样实现 |
|---|---|---|
| 真实人物 | 自然肤色差异、面部体积、局部毛孔、细毛和真实受光 | 机位与光确定观看重点，皮肤细节随区域和清晰范围出现，背景支持人物 |
| 塑胶或彩绘模型 | 模制体块、涂层、拼接及与部件相容的光泽 | 大曲面、轮廓及材料响应先可读，再保留该制作方式的必要细节 |
| 织物与绒面 | 织法或绒向、褶皱、缝合、受压和落地关系 | 整体先读柔软体积，纤维按距离出现；近景采用对应结构尺度 |
| 金属、木材与石材 | 曲率反射、加工方向、木纹色差、石材构造及来源特征 | 让主要色块和光面连贯，既有材料特征沿物件接续，关键局部获得足够面积 |
| 背景、服装与道具 | 身份、空间、环境和叙事需要的结构 | 按各自贡献分配反差、清晰度和面积，主视觉落点保持明确 |

已有粗糙表面、天然纹理和来源中的特征按任务保留。用户指定颗粒风格、磨损材料或密集工艺研究时，采用其明确的区域、尺度与强度，并继续组织大形与阅读顺序。当前选择覆盖默认外观，材料身份和物理关系继续成立。

按 [观看目的与成像选择](restaged-print-world-editorial.md) 组织整体。材料比较给关键表面足够面积，结构图用轮廓与遮挡表达连接，群体活动用空间和动作形成分组，印刷用版与基材组织层级。清楚的整体依照当前表现方式及实际阅读任务实现。

## 真实摄影任务执行控制链

真实摄影先识别被拍对象与用途，再共同确定空间、相机、光和成像处理，最后按真实观看条件检查。完整方法分别接到 [摄影](photography.md)、[光路](lighting-optics.md)、[材料](material-color.md) 与 [成像处理](image-development.md)。

| 环节 | 必须形成的具体决定 | 需要共同保留的线索 |
|---|---|---|
| 被拍对象与用途 | 真实人物、现有产品、模型实物、环境或材料研究；身份和当前状态 | 人物特征、产品结构、实际材料及用户保持项 |
| 场景与空间 | 机位、拍摄距离、背景、承托、接触、动作及主要空间分区 | 尺度、透视、遮挡、支撑和环境关系 |
| 拍摄与光 | 有作用的光面及暗面、光色、曝光意图、焦点和动静 | 体积、接触阴影、反射、透射及符合镜头逻辑的柔度 |
| 材料与成像 | 来源或本轮设计支持的表面、自然色差、亮暗过渡及处理范围 | 真实皮肤、织物、金属、木与石各自必要的材料线索 |
| 结果与证据 | 全图、交付观看尺寸和必要原生区域 | 主次、主体识别、空间连续及当前关键材料关系 |

### 真实摄影图生成与材料保真

先区分真人皮肤、彩绘模型、蜡、树脂和其他实际表面。真人皮肤按区域保留自然色差与细节，光滑塑胶按其制作方式反射，织物随褶皱与绒向受光。材料之间既有区别，也共享同一空间里的照明、曝光与接触。

主体边缘要足够辨认，同时让焦点、景深、动作和镜头条件决定局部清晰度。关键表面保留连贯明暗、真实厚度、接触阴影和环境反射。曝光与处理按当前光场及实际工具选用，真实 EXIF、制造数值与测量由对应记录支持。

这样落实用户要求的真实摄影与反塑料感：人物、材料、光、相机及环境共同形成可信外观。整体清楚与局部自然细节同时检查，各自服务本张用途。

## 参考图与局部修改

参考分别提供身份、构图、材料、灯光或图面，取用范围由本轮任务决定。源图可见的纹理密度按当前观看目标选择；需要严格保真的内容按用户范围保持。局部编辑沿 [明确的主图与变化范围](prompt-execution.md#局部编辑采用明确的主图与变化范围) 写改变、必要融合及保持项。

例如，只改变一个按钮盖的颜色时，让目标颜色及必要反射在当前场景内接续，其他材料与内容沿主图保持。用户要求整体视觉组织时，再共同处理主次、反差、细节尺度和背景。成像说明只包含采用的变化。

## 看图时按三个尺度判断

| 观察尺度 | 本轮要判断什么 | 下一动作的依据 |
|---|---|---|
| 整体与目标观看尺寸 | 第一落点、主体边界、大色块、空间分区及阅读顺序 | 调整构图、体量、反差或辅助内容的面积与清晰度 |
| 主体与关键局部 | 材料身份、结构、接触及准确图面是否共同可读 | 回到相应物件、光路、焦点或表面决定 |
| 必要原生区域 | 本轮依赖的边缘、肤质、纤维、加工、层序及细节尺度 | 判断实际可见范围，保留通过、待确认或需要修正的真实结论 |

整体层级、材料观感与用户反馈共同参与核心评审，脚本核对记录和传递一致性。原生细节用于判断图中实际包含的内容；新的独立近景继续保留自己的证据范围。实际图片生成和用户接受沿各自授权与审阅节点记录。
