# 研究内容与表达媒介

用于模型、成品、图稿、样片和辅助研究件的组合。先明确这件研究内容让观者理解什么，再选择表示方法与载体。研究件可是一张图，也可以是织样、刻痕、压印、薄片、线材构件或明确的数字画面。单件主视觉按其任务独立成立。

## 先选择研究的问题

| 需要解释什么 | 可采用的内容与表达 |
|---|---|
| 外形与比例 | 正投影、连续轮廓、单色块、线材外框、压印负形；选有用的视面。 |
| 部件与装配 | 轴测、爆炸、截面、透明叠层或实体分件，保持当前部件归属。 |
| 加工与状态 | 针脚路径、折叠展开、流动与凝固、模具印痕、表面处理对照；说明本次设计的过程范围。 |
| 材料与表面 | 实际样片、拓印式图面、近景影像、织样或同形不同加工，保留可比较的观察条件。 |
| 图形与识别 | 图标、像素、绣字、材料成字、分色、轮廓概括或抽象色场，保留本轮必要辨识。 |
| 内部节奏 | 孔隙、枝脉、放射网、分布或切片，采用可见资料或明确艺术概念。 |

完整外形、局部研究和工艺推演各有作用。为当前任务选择足够的内容；图稿数量与原始照片数量分别决定，模型与研究件依据同一身份及明确创作范围建立联系。

## 让媒介改变痕迹与结构

**技术图解。** 通过投影、截面、爆炸方向和引线组织阅读。线的粗细、虚实、数量及文字层级由信息决定；白底、深底或蓝底都应让当前结构清楚。尺寸、部件标记和工程信息采用资料或明确设计值。

**轮廓与色场。** 将当前对象的开口、转折或主色区概括为线、块和负形。可采用硬边图形、柔和色场、局部渐变或像素离散。先确定保留的形状与信息，再选择颗粒和边缘。

**接触、扫描与光影图面。** 让形体靠近成像平面，使用剪影、接触密度、重复片段或方向性拖曳。指定保持清楚的锚点及允许变形的区域；相应变形属于该图面。真实接触成像或扫描记录采用实际采集资料。

**结构显露与微观图面。** 用选择性透明、线框、切片、孔隙或伪彩展示某项结构。已知内容依据来源，开放概念说明设计范围。真实材料透明度与图面示意的显露方式分别设置。

**材料成形。** 让绣线沿路径成字、织面线圈转成纹样、蜡或软材留下负形、木面刻出轮廓、薄片叠成截面。材料的厚度、受力、收边与光共同决定痕迹，具体做法见 [材料与过程](material-process-atlas.md)。

## 说明内容怎样成为影像

按 [观看任务](restaged-print-world-editorial.md) 选择成品媒介：表面比较给材料足够面积，结构说明呈现连接和运动，群体场景用活动与空间组织阅读。当前图片可以直接是摄影、绘画或说明图，研究件按实际信息用途参与。照片原样嵌入时，核对来源区与实际映射。

重要效果用一句因果关系组织：内容在哪里，经过什么成像方式，在哪个载体中呈现，原生图里应看见哪项特征。先确定被表现对象与观察路径，再写颜色、边缘和细节。

| 当前表现 | 需要共同成立的可见关系 |
|---|---|
| 胶片中的内部裂隙概念影像 | 外部轮廓包围内部结构；裂隙与周围组织共同采用选定投影、密度、颗粒和清晰度。 |
| 屏幕上的像素文字 | 字形按屏幕像素与发光范围形成，画面透视、表面反射和受遮挡位置相容。 |
| 光穿过图形薄片投向墙面 | 图形、光源、墙面和遮挡有明确位置；投影随入射方向、距离和接收面展开。 |
| 刺绣或刻印形成的文字 | 字形由线材、针脚或加工痕迹构成，厚度、收边和局部阴影与材料对应。 |

在同一个影像窗口内，新增内容和周围结构共享这次采用的成像规律。真实采集记录使用实际数据；艺术概念把投影、密度及允许变形写为设计。载体选择随本次任务确定，已经指定的载体直接沿用。

评审时核对图形、内部与外部层次怎样共同形成。准确位置和文字内容各提供相应证据，图像机制还需由边缘、密度、颗粒、遮挡或传播关系支持。

## 为内容选择载体

纸张适合画、印、切与折；透明片适合叠层、刻线、色片和透射；织物适合交织、绣线与印花；木、金属、蜡及软材适合相应表面成形；屏幕与数字平面采用明确的图像表现。载体先有任务，再决定形状、边界、尺寸与摆放。

同一主题可以有不同载体。例如，开口圆环的装配研究用刻线透明片；线材转弯研究用织样或绳线路径；压印研究用正负形。图稿也可以直接成为主要视觉对象，其他物件按本张需要提供参照。

## 桌面纸稿采用什么图像语言

纸张可以承载不同的图像表现。先选这张研究什么，再选择对应方法；每幅纸上内容与本轮主体建立具体联系。

| 图像语言 | 可以研究什么 | 怎样写出具体画面 |
|---|---|---|
| 扫描与接触影像 | 轮廓、贴近平面的形体、方向变化与重复节奏 | 指定清楚锚点、允许拉伸或重复的区域及方向；接触密度与边缘属于该纸上图像。 |
| 微光与光点 | 轮廓显露、疏密、局部能量感或幻想体量 | 在纸上图面内安排暗色场、亮线、光点与局部光晕，保留必要形状。纸张的实际受光另行说明。 |
| 透视与技术图解 | 体积、部件、装配、剖面或开合动作 | 为图中对象选择透视、轴测、截面或爆炸关系，说明部件与阅读顺序；整张纸按自己的实际摆放形成透视。 |
| X 光式结构显露 | 外部与内部、重叠层次、连接及选择性透明 | 决定哪些外轮廓保持、哪些内部显露、哪些区域较密；真实结构依据资料，概念结构按本轮设计范围表达。 |
| 热成像式伪彩 | 图形分布、区域层次、轮廓或艺术色带 | 为当前图形选择有组织的色区与过渡，明确艺术配色；采用真实测量数据时按对应资料解释。 |

例如，同一器物的扫描式图稿研究外轮廓，透视图解研究连接，X 光式图稿研究内外层次，微光图稿研究轮廓的聚散。开放创作也可以让一张图面承担主视觉；纸稿数量与方法按当前任务决定。完整照片复制和已有批准图稿按其实际保持范围执行。

纸内的光晕和高亮可以通过图面明暗形成视觉效果；透光纸可以由所选底光照亮。需要发光作用延伸到桌面或相邻物件时，明确实际发光载体、传播和遮挡，再核对纸张的材料设定。图像的透明结构与纸张本身的透明度分别选择。

各张纸保持自己的图像窗口，内容随该纸旋转、弯曲、覆盖和受光。纸图与实体的深度、光效和变形分别定位，实际检查图面可读、材料与空间是否共同成立。

## 把平面内外分别写清

说明每幅图或每件研究物属于哪个实体、表达哪些当前主体特征、采用哪种媒介，以及它在空间中怎样摆放。载体转动、折弯或被遮挡时，附着内容共同变化；载体上的画面可以采用自己的投影和概括方式。

例如，透明片上印的是扫描式拉长的圆环轮廓，片材本身仍是平整薄片；木片上的圆环是凹刻，只有刻痕形成起伏；线材圆环由实际线径、转弯与支撑成立。纸上描绘金属高光与实体金属反射分别检查。

## 将研究内容组织为构图

根据研究任务选择同轴对照、正负形、大小层级、环绕路径、散置清单、网格、簇群或前后显露。解释装配时让分件方向清楚，比较材料时让观察区相邻，表达流动时让路径与承接面连接，强调空隙时给它可见的边界。

真实工具、手、包装和其他道具按其功能与画面贡献进入。完整静物保留必要边界和台面余量，明确局部或艺术图面按选定窗口构图。需要精确平面预算时，使用 [可选取景计算](framing-preflight.md)。

## 判断研究是否成立

先看它是否解释了当前主体的一个具体问题，再看身份、媒介、载体、空间与必要信息是否相容。要求多方向探索时，比较各方案研究的问题、痕迹形成方式和构图差异；实际图像按其原生线索评审。

示意图、加工概念与制造证明分别保留依据。选定的印刷任务按 [印刷判断](print-direction.md) 安排纸墨或织物；其他媒介按当前工艺与 [实物验收](physical-realism.md) 采用相应核心项。
