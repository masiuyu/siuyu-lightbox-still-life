# 把风格迁移到新的主体

适用于从参考提取视觉方法、系列换题材、跨画幅重排及新媒介适配。用户只要求单张或已经确定局部修改时，直接应用相关判断；额外图片测试按实际授权执行。

## 先分清什么需要保留

| 本轮需要确定的内容 | 可能包含什么 | 决定依据 |
|---|---|---|
| 主体身份 | 部件、轮廓、连接、材质、识别色、必要图面 | 当前实际来源、用户要求或明确的新概念 |
| 系列视觉关系 | 视点、明暗组织、色彩分工、空间密度、边缘与细节分配、媒介表现 | 参考中实际可见且本轮选用的关系 |
| 本张具体实现 | 摆向、尺度、分组、光面、纸层或背景、允许裁切与焦点 | 当前主体、用途与画幅 |

颜色和材料可能属于主体身份，也可能是开放设计的一部分。先确认本轮的归属，再决定参考可以影响什么。新产品需要保留的红色、透明范围与表面处理，继续服从该产品要求。

表现机制改变时，按 [观看任务](restaged-print-world-editorial.md) 重新指定来源角色。材料摄影、结构图、群体活动和主题视觉需要保留的内容各不相同；先保留身份与用户指定关系，再为新对象选择投影、受光、密度及信息表达。跨题材验证检查这些决定是否适合新条件，具体来源启发沿 [方法归属](method-sources.md) 记录。

例如，参考中的金属器物可以启发“浅底上用清楚亮暗解释体积”。换成有釉陶器时，保留的是浅底、主次和体积阅读，釉面用自己的反射成立；换成透明玻璃时，补充厚边与背景透射。每个题材按自己的材料行为实现共同观看方式。

## 从参考提取可执行的关系

先描述参考里实际看到的结果，再选择与本轮有关的部分：

- 视点与空间：相机怎样观看，物件是平面分组、层叠还是纵深展开，哪些轮廓完整。
- 光与明暗：亮部和暗部各在哪些表面，主体与背景怎样分开，哪些细节被强调。
- 色彩分工：背景、主体和点缀如何分配明度、色相及饱和度，参考中的色偏来自哪里。
- 边缘与细节：哪些地方清楚，哪些地方概括，纹理在整体中占多少视觉重量。
- 构图节奏：大形怎样互相呼应，空隙怎样连接分组，视线如何从主体到辅助内容。

只采用能改变本轮决定的关系。参考中某件道具只有在当前图里承担实际任务时才保留；新题材的研究图依据新主体重新设计。艺术家或摄影类型名称可以帮助定位，实际成像说明仍需写出选用的可见特征。

同时判断图像通过什么方式形成：线圈和绣线形成轮廓，蜡的正负形形成体量，磨砂界面控制遮显，扫描条带改变时间与方向的观感，微观结构改变观看尺度。这些机制会影响研究稿、材料、空间与光，迁移方法见 [视觉语言](visual-language.md) 和 [研究媒介](study-artifacts.md)。

然后把抽象关系绑定到当前物件。“克制而温润”可以具体化为：“器皿占主要观看面积，有釉曲面保持连续柔亮反射；纸面石墨线局部清楚，台面大部分保持平静，主体与图稿之间留出可读间隙。”如果要改成强烈切面感，则重新选择明暗边界、摆向和细节分配。

## 写出保持关系与允许变化

系列规则要足够具体，能指导下一张图，又能容纳新物件。可写成几句自然语言：共同采用什么观看方式，主次由什么形成，背景和主体怎样配色，哪些材料关系必需，以及哪些位置可以随画幅改变。

例如：“共同垂直俯拍，主体先被看到，辅助图稿解释同一对象的结构。乳白台面从分组之间连续露出，纸张覆盖同一石墨线时降低其反差。材料身份由当前对象确定，物件位置与纸张朝向按画幅组织。”这组关系适合光台研究；单件主视觉可以只保留背景、形体与光的对应，不必加入研究纸。

用户锁定位置、颜色或构图时，保持该范围。开放系列可以重新安排大形、空隙和对比，具体方法见 [形式发展](design-development.md)。媒介从摄影变成平面插画时，说明保留哪些主次、色场与形状关系，以及哪些材料线索通过线条、色块或笔触转译。

## 稳定规则与条件变化各有范围

系列先确定少量跨题材仍有用的观看关系，再为不同明暗环境、材料和镜头写具体实现。单张已选的物件、位置和光色属于该张的约束；反复成立的视觉逻辑才逐步成为系列方法。规则需要说明允许变化，条件分支只写与稳定部分不同的决定。

例如，同一系列都要求玻璃瓶口、壁厚与液位清楚：浅环境可用适当暗边和背景透射读形，暗环境可用侧边反射与局部亮区读形。共同规则是必要结构与材料身份可读，两种环境分别选择有效光面、明暗分配和曝光。抛光金属、绒布及纸上图形也按各自成像方式实现系列联系。

每次实际反馈先定位影响的是系列关系、某种条件下的做法，还是当前单图。把调整写回相应范围，下一张从当前主体重新实现。单张资料支持当前关系的观察，多场景、多材料的实际结果逐步支持可迁移性。[项目风格系统](https://github.com/ajinnaaa/extract-visual-style-2/blob/7b7d2c285e84805dd2f324dc815911573b5df6e6/extract-visual-style-2/references/project-style-bible.md) 提供稳定核心、条件实现和当前场景约束的分层启发。

## 选能揭示问题的新题材

形成可复用的系列方法时，选择新主体去检验一项真正不同的条件。常见选择包括：

| 想检验的能力 | 有用的新条件 | 重点观察 |
|---|---|---|
| 风格能否容纳不同材料 | 从金属换为陶器、玻璃、木材或织物 | 新材料身份与共同视觉关系是否同时成立 |
| 是否依赖原主体形状 | 从圆润单体换成长形、有开口或多部件对象 | 新轮廓与连接正确，原题材的部件与装饰不会自行进入 |
| 是否能适配画幅 | 横幅与竖幅分别组织同一任务 | 主次、完整性和必要关系延续，布局有实际调整 |
| 是否只靠背景色维持相似 | 改变主体固有色或明暗重量 | 主体颜色被保留，光与空隙仍能建立系列联系 |
| 是否过度依赖已有对话 | 在可用的独立上下文中只给任务、必要原图与风格说明 | 说明能自足执行，结果达到预先写明的观看要求 |

按当前最不确定的一项选择探针，图片数量服从授权。先改变一类条件有助于定位问题；同时改变材质、布局和画幅时，把它记为综合适配，结论停留在该任务的结果。独立上下文测试由实际可用且获授权的执行方式完成。

## 看图时分开判断三件事

多样探索另对照各方向选定的差异。隐藏题材名称与风格标题，比较大形、密度、边缘、媒介形成方式和光影作用；在不同主体上追踪实际的设计改变。严格一致的产品系列沿其锁定关系评审，开放探索按各自观看目的判断。文字方向只说明选择，实际差异需要成图证据。

**身份是否成立。** 对照新主体的来源与要求，检查形状、数量、颜色、材质和内容归属。新的视觉处理要在这些条件内工作。

**所选风格关系是否可见。** 先按整体观看大小比较主次、大形、色场和空间，再看光、纸层、反射与细节分配。相似背景色只覆盖其中一项，不能替代其他已选择的关系。

**变化是否有目的。** 检查本张新增内容怎样服务新主体，画幅调整是否改善观看，风格参考中的对象是否被误当作新图内容。故意保留的系列道具或符号按本轮明确设计核对。

测试前在工作记录中写明当前题材的必要结果。成图后按具体位置记录通过、需要修正和待确认；每个结论对应自己的范围。一次成功是一份适用证据，跨题材可靠性由不同条件下的多次结果积累，用户审美接受另行记录。

## 失败以后回到哪一层

| 可见问题 | 优先修正的关系 |
|---|---|
| 新物件出现原参考的部件或纹饰 | 重新说明当前身份及各参考用途，按来源关系核对归属 |
| 所有物件都呈现相近镜面外观 | 为各材料重新指定反射、透射和起伏，检查风格说明是否覆盖了材料身份 |
| 构图相似但对象难以识别 | 调整当前对象的识别面、尺度、遮挡与必要对比 |
| 原色被统一色调改写 | 将系列色彩安排在允许的背景、辅助内容和反射范围 |
| 新题材正确，但系列联系较弱 | 检查预先选定的视点、主次、空间密度、光与边缘分配中哪项没有落实 |

局部材料问题使用 [材料判断](material-color.md) 与 [光路设计](lighting-optics.md)；主体归属问题使用 [来源关系](object-relations.md)。保存新版本，明确一项主要修正目标和其余保持项。

## 方法依据

社区 [Style Prompt Guide](https://github.com/indigokarasu/imagine/blob/main/references/style_prompt_guide.md) 提供风格与内容分开思考及新主体测试的启发。本指南按当前任务保留材料和颜色的身份作用，用可执行的关系组织系列，并按实际试验范围判断适用性。提示词次序、长度与表达方式由当前工具和任务选择；实际成图是效果依据。
