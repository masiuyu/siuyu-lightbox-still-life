# 场景状态与情境搭配

用于把来源中的主体放入新的光台场景，以及从地点、文化、生活情境或使用关系自主发展搭配。先确定主体怎样存在于目标画面，再决定周围内容与它发生什么关系。与 [结构与解构表达](subject-structure.md) 配合使用，主体保真和垂直俯拍继续成立。

## 识别主体、载体与场景状态

阅读来源时，按 [来源关系与呈现范围](object-relations.md) 分别识别主体稳定的身份与结构、活动与周围物件，以及图像自身的呈现方式。把关系、目标范围和依据写进 `content_analysis` 后，再用 `preserve` 提取需要保留的具体特征。首次上传、生成图参考和旧方案复用都从实际来源完成这项判断。

先用一句明确的对象名称说明用户所指的主体，再按 [来源识别](object-relations.md#先读原图中的关系) 逐项区分组成、装配、承托、产生与图面关系。石雕的本体依据是雕刻体量、开口、纹样和可确认的接合；台座按实际归属单列。建筑、植物和器物同样从可见构造建立部件清单。对象的功能和现场活动按作用关系记录，随后从已经确定的部件中提取辨识特征。每项结论以可见来源或用户说明为依据，材料判断遵循 [材质证据](material-color.md)。

多轮改图时，原始主体资料与用户明确接受的内容提供身份依据；生成图提供本轮明确采用的布局、风格或编辑范围。逐项重建当前保留项，记录来源与用途。用户已经确定的实体、模型、照片或图稿呈现方式作为当前任务约束继续执行。

本轮有新上传文件时，先逐张打开并建立当前 `inputs`。观察、保留项与实际路径记录在同一条中，再通过 ID 引用。旧图的具体参考用途与用户明确接受的内容分别记录；接受依据应能对应到用户表达。编译后逐项对照 `Image N` 与实际参考文件的观察。

按已经确定的呈现方式理解内容：实体或模型在目标场景中具有自己的支撑、尺度与状态；照片和画稿将所记录的场景呈现在各自图面上。纸面中的动作属于图像内容，纸面外的物件按目标场景的物理关系组织。保留范围与载体一起明确。

静物任务默认采用稳定静置的物件状态。造型物可以通过张口、屈身、挥手或其他定格姿态表达动作，其实体构造、连接与承托符合这个造型。目标包含实际操作或运转时，按场景需要设计相应条件。对象身份、所选造型与实际拍摄状态分别说明。

先回答所选状态对本轮表达有什么作用，再设计使它成立的条件。若一种状态需要明显扩展装置、辅助物件或主体材料假设，回到交付目的比较更相容的呈现方式。`scene.intent` 记录选择理由，`scene.support` 记录承载；状态可行性与选用价值分别判断。

## 旧方案的本轮复核

新任务使用本轮输入和 Skill 包内的字段示例建立方向。跨任务的成图、方向文件与评审，在用户明确指定复用时读取；同一任务延续已确定版本时，按该版本的实际接受范围读取。文件位于同一工作目录，只用于定位已经指定的资料。字段、JSON 结构与调用方式以 Skill 包内示例和当前脚本为准。

符合上述复用条件时，先仅根据当前请求和实际来源写出对象、载体及稳定部件范围并保存，再读取旧方向中的具体设计。默认选择按 [来源关系与呈现范围](object-relations.md) 执行。已有旧资料进入上下文时，仍用本轮来源独立完成这份判断。用户的接受依据应能定位到原始表达；简短的继续要求沿用当前任务中已经明确的范围。

- 用户明确确认的构图，按其确认的分组、间距、观看顺序或其他具体关系保留；明确确认的外观和制作要求也各按其范围执行。其他设计决定继续对照当前目标、来源和工艺复核。
- 对准备采用的旧内容说明：它对应哪项当前用户要求或来源结构，本轮用在哪里。旧版本的范围清单、作者说明和通过记录作为待复核设计处理；当前用户接受的具体内容按其确认范围落实。将结论写入现有方向字段，保持摘要简短。
- 主体范围、载体或制作结构需要重建时，更新对应保留项、材料、连接、承托与验收目标，采用 `recompose`；仍成立的空间关系可以保留。用户明确要求的局部编辑继续限定在该范围内。
- 根据复核后选用的关系决定是否把旧成图传入工具。布局关系也可以通过方向文字保存；所选参考的用途须与本轮需要实现的形体、材料和工艺相容。
- 编译前从输入、主体依据、搭配、材料和验收目标顺序读一遍，确认它们表达的是同一份当前设计。采用当前实际查看的文件记录观察；来源暂时不可读取时，如实记录可核验的范围。

## 生命题材的实体呈现

人物、动物等生命题材作为台面立体主角时，默认采用具有明确设计尺寸的模型。根据当前主体与观看目标，自主选择缩尺、写实或概括程度、体块、姿态、材料与配色。植绒、打印彩绘、玻璃、陶瓷、纸塑、模块拼搭和其他工艺提供不同表达空间，具体按 [模型尺度与建构](model-construction.md) 决定。用户给定的要求优先。

用户以原物身份提供的既有模型或手办素材，按来源保留材料、工艺和外观。以下制作设计用于本轮从主体资料新建的模型。

**所需辨识由来源与任务确定，形体与材料由当前模型设计建立。** 先选择能辨认个体、对象类型或主题的特征组合，再决定它们怎样通过造型和工艺呈现。面部关系、耳尾轮廓、花纹或服装等按具体识别目标取舍；身体比例、姿势、细节、透明度与配色可以依所选表达重新设计。来源只展示局部时，可选择局部造型或设计完整形体，并分别记录来源依据与本轮设计内容。

让制作方式在模型的实际尺寸和交付观看尺度下可读：体块形成整体，连接与厚度解释承力，表面处理表达所需细节。先按真实手办与所选工艺确定成品高宽长，再按需要计算缩尺并设计对应细节；画面可以通过近摄放大观察。模型的所需辨识、完整建构、所选材料与摄影表现分别核对。

在 `subject_basis` 和 `inputs[].preserve` 中写清本轮识别依据与用户锁定项；在 `scene.carrier` 中写造型、制作方式、缩尺或设计尺寸，在 `materials` 中用 `designed` 写材料、表面、颜色转译和光响应。`composition` 与 `support_and_motion` 共同安排实际尺寸关系、稳固接触和朝向，使关键识别面在垂直俯拍中可见。`review_targets` 分别检查所需辨识、所选造型、尺寸、工艺与承载。

照片与图稿按各自图面承载人物或动物形象。手持纸张、摆放模型或操作工具的工作手按场景动作设计，其角色与作为展示对象的人物造型分别说明。用户明确要求现场人物、动物拍摄或其他载体时，按该要求重新确定尺度、环境与状态。

## 呈现方式变化时重新建立保留范围

“把照片里的主体做成实物或模型”“把图稿改成实物”“改成一张照片纸”等请求改变了内容的载体。编辑区域的大小决定局部范围；主体范围与状态仍需按新载体完整判断。

先确定用户要求呈现的是一个对象、一个复合场景，还是一幅完整图像。**简短的光台生成请求默认按主体对象建立静物；单体模型由该对象独立存在时的固有结构组成。** 穿着、实际装配配件和容器内容按来源中的归属确定。主体清单成立后，再提取识别特征并设计造型；新绘制的模型研究图使用相同的部件清单。复合场景模型或现场研究图依据用户明确提出的场景目标设计，完整图像按指定图面保留。

回到原始来源和用户本轮要求，逐项解释此前保留内容的含义：

- **主体实体**：可确认的固有部件、结构与外观，形成新载体中的身份保留项。
- **图像记录的场景**：拍摄时的动作、周围环境与相互作用，按用户要求的完整图面或场景目标确定采用范围。
- **当前设计内容**：承载、图稿、材料样片等辅助内容，按用户要求与实际构图贡献确定，并与主体部件分别说明。

先逐项判断部件归属，再选择制作方式：该部分表现什么，在原始来源中属于哪个对象，以什么稳定结构或使用关系归属，依据是什么。主体归属由来源关系与任务范围建立，材料可行性用于选择对应做法，两项分别给出依据。定格造型的内容范围按其表现对象判断；原物的固有部件由结构归属确定，新建模型的概括、夸张与材料转译围绕该范围中的识别目标展开。单体模型的材料设计用于这份范围内的形体、连接和表面；本轮辅助物件具有自己的对象身份与承载。对于主要表现某次动作或环境的内容，依据明确的场景目标安排到相应图面或场景层。

单体模型场景中的新增道具按各自独立物件身份选择，例如工具、纸稿、材料样片、器皿或其他有依据的实物；分别说明其本身的构造与用途。主体研究图按 [图稿内容选择](subject-structure.md#图稿与道具的选择依据) 确定内容。需要呈现完整现场时，先落实用户明确要求的场景范围，再设计其中各实体或图面。

用一小段 `decisions.subject_basis` 写清新载体中的主体范围、各层用途及保留依据。随后重建转换区域的 `inputs[].preserve`、`pairings`、`materials` 与 `review_targets`；相邻的已接受内容按其原有图面或实体用途保留。载体或制作结构重建采用 `recompose`；搭配已确定时可用 `directed` 记录当前选择。

生成前按下节完成主体与建构审查。`static`、材料名和编译结果分别描述状态、材料与字段传递；主体归属、结构连通和承载关系通过来源对照与方案审查判断，再以成图确认。验收目标由审查后的实体范围与制作结构确定。

## 主体与建构审查

新建模型、转换主体载体或重做其建构时，在实际编译前完成以下审查。主执行者负责落实每项；采用独立审查时须符合当前用户授权与工具能力，审查范围限于所给资料、当前要求和当前方案。

1. **先确定来源范围**：仅依据原始主体资料、当前用户请求及其明确确认的范围实际看源图，保存文件路径、对象观察和来源结论。用 `content_scope` 记录默认主体研究或用户明确指定的内容范围，`content_analysis` 写有限部件清单、关键边界及独立物件与图面用途。完整场景和完整图面的依据逐项对应用户原话中的内容要求。采用独立审查者时，先提供这些原始资料和请求，待其形成来源结论后再提供设计。
2. **再核对方案**：作者按上述范围和 [模型建构](model-construction.md) 完成方向记录，再对照来源检查；采用独立审查时交给同一审查者。逐项列出方案中的实体部分、图稿、造型样片和材料样片，按所表现内容核对原始归属及采用依据。候选 `source_relations` 覆盖全部内容类别，造型研究与主体共用部件清单，材料研究对应选用的制作材料。随后检查主要体块、分件连接、细节尺度、工艺与材料、承托是否相容。来源段、搭配、材料和验收目标使用同一范围，范围依据与制作条件分别成立。
3. **落实结论**：用一份简短的 `subject-review.md` 保存来源观察、方案判断及所审查的方向版本；说明观察怎样支持判断。检查各段中的主体身份与当前输入文件逐一对应，并按 [实物真实性](physical-realism.md) 核对主体、承托与每类辅助物件。将所选工艺需要呈现的整体形体、表面和连接特征写进验收目标。存在需要调整的部分时，先修正方向，再复查相应范围；通过后编译该版本。
4. **成图回看**：先仅依据原图和任务重新列出应有对象、主体部件及载体，再与方向和成图比较。将这项来源范围比较单列为核心项，具体要求写出来源结构或用户目标。随后检查造型、工艺、连接、承托及全部道具。采用独立审查时也把实际图片交回审查者。按 [成图判定](physical-realism.md#成图判定) 记录位置、所见、要求和结论；需要修正时继续使用方向、编译、调用的同一执行路径。

审查者只完成所分配的来源判断、方案复查与实际看图；成像操作者负责编译和调用。作者复查与独立审查如实记录，并采用相同的来源、构造与成图标准。用户只要求分析、改 Skill 或生成前准备时，执行到所授权的阶段并记录其范围。

生成图提供的参考关系按用户明确采用的范围使用。参考段只记录本轮选用的光照、色彩、分组、间距或其他具体视觉关系；用户以原物身份提供的来源继续承担主体身份依据。重生成或转换载体时，逐项写出真正采用的内容和来源。

## 让动作与现象有成立条件

为画面中的动作或动态现象说明产生条件、来源与支撑、运动路径、终点或作用面，以及相关表面的反应。检查这些关系能否在同一个尺度和空间中成立：手部与物件的受力、材料的承接、容器与内容、接触处的状态变化都服务于所选场景。

`decisions.scene.state` 描述实际拍摄空间，取 `static` 或 `active`。静置场景的 `activity` 为 `[]`；活动场景在其中简述完整的动作条件与作用关系。照片或画稿上记录的内容仍按其图面用途说明。

将动静状态写进 `design.composition` 与 `photography.support_and_motion`，把需要可见的作用关系写进 `review_targets`。快门与清晰范围服务于已经成立的动作关系。生成前对照主体约束、场景状态和摄影描述，调整相互冲突的决定后再调用。

## 从情境发展辅助内容

从用户说明、来源中可确认的信息和本轮创作目标提取关联线索。模型可以沿地点、文化、时代、季节、工艺、使用仪式或生活情境发展新的搭配；也可以找到这些示例以外的关联。以当前主体与表达目的判断关联的意义。

辅助内容可以是地方食物及包装、工艺物件、织物、器皿、植物形态、旅行材料或日常用品，也可以是图稿、色场与负形。根据观看重点自由选择、组合和发展，让主体与所处的世界产生可读联系。

开放设计先比较至少两个不同的联系：从可见特征出发，也从有依据的使用、地点或其他情境出发。镜头、灯光和风格服务于这些内容的呈现。内容边界依据用户明确要求与主体真实性确定；候选线索由本轮观察产生。

每项只写简短的决策摘要：`lens` 为自由命名的联系角度，`cue` 为触发线索，`source_relations` 为所表现内容的来源类别。`basis` 将内容逐项对应到主体结构、当前制作材料、独立物件身份或用户明确的内容要求；`proposal` 为范围内拟呈现的内容与创作做法，`contribution` 为可见贡献，`scene_fit` 为尺度、载体和承载适配。先按 [来源范围](object-relations.md) 确认采用资格，再比较候选怎样改变观者理解主体的联系；分别换名或换色的相近方案需要合并。

具体地域、文化、历史或具名物品的关联以用户资料、可确认的来源或可靠资料为依据。需要补足这类信息时，进行范围明确的核查，优先采用相关官方机构、博物馆或原始资料。说明关联适用的地区与情境；跨地区共有的事物可以按实际联系使用。本轮创意联想以创作意图表达，真实个人经历、行程与票据信息依据用户提供的内容。

## 同时判断意义、画面作用与承载

为选中的辅助内容说明：它怎样联系主体或主题，在画面中贡献怎样的形状、颜色、材料或观看节奏，以及以什么形式进入台面。每个保留元素的作用应能在图上看见；根据实际贡献决定数量和视觉重量。

安排好各类物件的容器、衬垫或支撑，以及它们与纸张、织物和主体之间的接触。食物、饮品、材料样片与文档各按自己的物理属性呈现。包装与图面是明确的内容载体，文字、标识和事实性信息按对应来源处理。

主体模型与辅助物件按各自的实体尺寸建立可信台面关系。每件模型的原型缩尺单独说明，纸张、工具与手按自身实物大小参与拍摄；同一套微缩场景中的成员遵循该场景的缩尺。通过相对大小、位置、间距和明暗保持主次。已有明确主题时直接细化，仍有关键选择时简短比较可见差异。

按主体保真、表达价值、视觉贡献和场景复杂度选择候选，把结果记入 `selected`，以 `selection_reason` 简述取舍。可选择多个互补联系，也可集中于一个；道具数量由构图贡献决定。选中联系必须在 `pairings` 中有实际对应，候选记录作为本轮选择的可复查依据。

## 写入实际提示词

- `inputs[].use`、`content_analysis.target_scope` 与 `preserve`：正面描述本轮采用的主体、载体、稳定特征、研究内容及可见边界；完整观察与范围依据保存在方向记录中。
- `decisions`：记录身份来源、主体依据、所选场景、不同联系的候选及最终选择，字段与编译要求见 [提示词执行](prompt-execution.md)。
- `design.idea`：连接主体证据、情境关联与本轮观看重点。
- `design.pairings`：用 `relation` 说明辅助内容的关联依据、创作性质、载体和摆放，用 `purpose` 说明其可见作用；`sources` 指向实际内容输入，`decisions` 指向采用的候选 ID。
- `design.materials`：分别描述主体、辅助物件与承载材料的表面、内容及光响应；本轮设计的模型制作材料与辅助材料采用 `designed`。
- `design.composition` 与 `photography.support_and_motion`：共同确定垂直俯拍、尺度、承载方式及动静状态。
- `review_targets`：选择当前画面需要核对的主体保留项、状态与作用关系、情境关联和主次。

实际编译选择后的场景与联系、构图、材料及摄影设置；完整候选与取舍保存在方向记录中。编译器检查内容范围与候选类别的相容性、字段、引用和覆盖，来源真实性与联系是否成立由操作者对照原始资料核查，最后以成图验证可见结果。

## 成图复查

对照原图确认主体身份与所选范围内的完整结构；原物核对来源材料，模型核对识别特征和可见制作方式。再按所选载体核对台面空间、尺度和场景状态。动作或现象需要在图上具备可读的来源、路径与作用关系；发现冲突时，先修正目标场景与实际提示词中的相关决定，再按问题范围重新成像。

随后确认辅助内容与地点、文化或生活情境的关联有依据，其视觉作用能直接看见，容器、衬垫与接触关系可信。按 [全场景实物验收](physical-realism.md#成图判定) 记录每类物件在实际图中的证据，核心项逐项通过后才判定达到要求。
