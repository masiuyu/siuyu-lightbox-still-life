# 摄影美术指导与搭配

## 参考观察先于方案

先说参考里实际发生了什么：什么先被看见，最大明暗块在哪里，物体怎样分组，颜色占据什么面积，哪些接触、边缘或遮挡建立空间。再把适用关系转化到本 Skill 的垂直俯拍中：主体身份来自输入，材质按原物或模型载体确定，摆放朝向和取景服务于光台正上方的观看。

例如，发光底面上的深色金属意味着“控制顶部补光，让实体成为有重量的暗部”；薄膜重叠的颜色意味着“用厚度变化组织色场”。观察与转化分开写，方便回到原图核对。

## 用主体特征提出画面主张

先沿用 [默认视觉目标](../SKILL.md#默认视觉目标) 或用户明确选择的方向。光台研究静物将主体与图稿、材料或有用途的道具组织成可读的观察关系；取景、照明和色场共同服务这组关系。单件主视觉、动作与特写按相应的明确目标构图。

先按 [来源关系与呈现范围](object-relations.md) 明确本轮的对象、部件和图稿内容，再从该范围内的轮廓、开口、数量、表面工艺、功能或已确定的场景关系中选一个观看重点。用一句话说明希望观者看到什么，并让构图服务它。

[材质与配色判断](material-color.md) 将主体特征转化为创意和颜色关系：先确认外观证据与表面差异，再选择承载这项主张的形状、材料、色相、明度和面积。参考中的拍法与本轮主体共同提供依据。

在本轮已确定的视觉目标内，一个产品可选择不同观看重点：几何结构可由形状呼应表现；轻薄可由透光层次表现；触感可由材料对照和侧光表现。用户选择动作或近摄时，再通过相应取景表达。主张据此组织本轮选物和拍法。

自主设计模型、图稿、道具或结构表达时，按 [从主体发展结构](subject-structure.md) 从具体观察推导。原物按其保真要求呈现；新建模型以本轮所需辨识为依据，自主选择成品尺寸、写实或夸张造型、局部比例、材料与配色。模型及图稿、样片、摆放都可承担创意，所选工艺与物理关系共同支持表达。

主张也可从主体与地点、文化、使用或生活情境的联系展开。按 [场景状态与情境搭配](scene-context.md) 选择有依据的辅助内容，并先明确主体在目标台面中的载体、尺度与状态。

新建台面模型时，按 [模型建构](model-construction.md) 联合选择识别特征、成品尺寸、造型和工艺，再建立主次体量、连接与表面。植绒、彩绘成型、透明材料或其他制作方式通过不同形体表达同一对象；每件模型的构造与周围图稿、样片和工具可形成具体对应。

## 现实器物的结构依据

器物概念先选清楚现实品类，再列其功能部件与制造关系。轮廓、开口、容腔、连接和厚度要能一起解释它怎样被使用。例如咖啡勺的凹碗与勺柄连续成型，杯口、杯壁、杯底和把手组成可用容器。图稿沿这些具体部件展开轮廓、剖面或表面比较；工艺样片采用真实可加工的条片或矩形样件，厚度与所比较材料相容。

新建模型按其来源、识别目标和用户选择发展造型；每个概括形体仍有明确所指和可信做法。把整体辨识、功能开口和主要连接先落实到构图，再细化表面纹理。

## 选物与搭配

先看已有素材能承担什么，再考虑场景需要的材料。每个保留物件或材料区域应有可见的作用：

| 关系 | 设计动作 | 判断依据 |
|---|---|---|
| 形状呼应 | 圆回应圆、直边回应长轴、间隙延续轮廓 | 观看顺序能沿形状发生联系。 |
| 形状对比 | 曲面与直线、细长与厚重、开口与实心配对 | 主体特征因对比而更明确。 |
| 材料对比 | 透光载体衬托不透光实体，粗纹理邻接平滑表面 | 光与触感差异在图中可读。 |
| 色彩联系 | 根据主体选择冷暖、邻近、对比或中性色关系，并分配产品色和环境色的作用 | 面积、饱和度、明度及反射范围共同控制视觉重量。 |
| 观察与推演 | 用图稿展开主体的一项可辨特征，选择对应的线条、细节、纹样或空间层次 | 图稿中的具体对应能回到主体核对，资料与概念研究各有依据。 |
| 工艺或使用关系 | 有来源依据的辅助样件、工具或动作与主体发生联系 | 关系由任务内容支持，且在图上成立。 |
| 地点与生活情境 | 从主体可确认的关联中选择食物、包装、器皿、工艺物件或其他辅助内容 | 关联依据明确，所选物件同时贡献可见的形态、材料或观看节奏。 |
| 尺度与间距 | 以大形、细长形和小圆点建立节奏 | 疏密变化让观看顺序持续推进。 |

用户选择单件主视觉时，产品与色场、底面、光和负形之间的关系就是设计对象。光台研究静物将主体与研究或搭配材料组织成少量清楚的组。必要性通过比较判断：该元素加入后，主体识别、信息、节奏或材料关系具体改善了什么。

跨品类搭配可以由共同形态、动作、材料或主题建立。选择道具时，把它与主体的联系落实成能看见的编排；主体所属行业和参考中的物件只提供推导线索。纸上图稿的侧视、透视或剖面服务于辅助表达，整幅静物保持垂直俯拍。

## 分开控制四个维度

| 维度 | 可选择的控制 |
|---|---|
| 内容与密度 | 单件、少量组合、多物清单；主体数量与辅助材料分别决定。 |
| 构图与取景 | 在垂直俯拍下选择紧凑平铺、连续斜向布局、错位轴线、形状环绕、局部切边或材质近摄。 |
| 光照与影调 | 强透光、乳白扩散光场与纸层密度、侧向掠射、克制顶光；明确什么发亮、什么压暗。 |
| 色彩与表面 | 中性、单一大色块、有限撞色；纸、颜料、薄膜和实体材料各有任务。 |

这些维度可以组合。强透光多物平铺可加入大面积色块；单件产品也可在透光色层上形成主视觉。按本轮素材和观看重点取舍。

柔光箱与硫酸纸参考按 [柔光纸层档案](diffused-paper-archive.md) 组织乳白光面、半透明纸层和实体前景。整组陈列、单张手持和局部压纹都从光台正上方观看，再分别决定密度及拍摄高度；纸层边界与遮挡形成细微明暗，颜色沿用本轮主体和配色目标。

[摄影设定](photography.md) 提供这些方向的拍摄起点。选一个预设，再覆盖场景需要的项目；构图、配色与物件身份继续由本轮设计决定。参考观察、搭配理由和构图决策顺次保存在同一份方向记录中。

## 构图推敲

先确定相机在承载面正上方、光轴垂直台面的俯拍关系。通过立体主体的摆放与支撑，使其关键识别面进入镜头，并建立可信的接触。再想象只留下大形和明暗块时的画面，完成细节：

- **视觉重量**：综合面积、明暗、饱和度、边缘复杂度和朝向决定主次。
- **分组**：用靠近、同向、接触、对齐或共用材料建立组内联系。
- **疏密**：明确一个相对紧的区域与承担阅读或张力的开放区域；全幅密集时用窄间隔保持分辨。
- **边缘**：选一两条能组织画面的长边或轴线，由主体曲线、局部切边或错位产生变化。
- **负形**：产品孔洞、物件间隔和材料之间露出的底面共同构成图形。
- **色场**：决定颜色是主形、支撑面还是小面积呼应，以及它如何接触主体。

生成前比较的候选共同满足当前视觉目标，在主张、关键搭配与构图机制上形成实质差异。默认光台研究方向中，每个候选都要说清：主体的哪项特征对应什么研究内容，底光穿过哪些材料，以及这些物件怎样构成一幅完整俯拍静物。选定这组关系后再细化各件物品的尺寸与工艺；成像后按同一目标评判。

## 横竖画幅与连续桌面

默认横幅 16:9，竖幅 9:16，用户指定优先。为两个方向分别安排分组：横向可沿主体与研究的关系展开，竖向可用上下错位形成观看顺序。各方向都先确定主体的视觉重量，再给辅助研究足够的可读面积。

连续干净的承载面延伸到四边和四角。完整静物让每件必要物品的边界位于台面余量以内；纸张、样片与主体之间保持有用途的间隔。动作例按实际握持安排手腕进入。局部取景用于用户明确选择的细节目标。

把构图要求写成具体可见关系：主体首先可辨；研究能指出所对应的部件或工艺；必要轮廓完整；辅助物之间有明确组内联系；至少一处留白让主要形体易于阅读。成图从整幅缩略观看开始，随后检查结构与细部。

## 光与材料

照明说明同时覆盖主光、补光、实体暗部、透射层与接触。

先确定物件的动静状态、支撑与相互作用，再用照明和曝光呈现。动作与现象的来源、路径和作用面应在同一场景中成立；静置物件用接触、材料与形态建立真实感。

结合景别、机位、镜头、ISO、光圈、快门与对焦范围，说明这种布光在图中应该形成的结果。材质近摄、静止平铺与手部动作分别选择相应的清晰范围和曝光策略。

- 强透光静物：发光表面主导曝光；不透光物件形成暗部，少量反射勾出金属体积。
- 柔光纸层：用大面积扩散光面、适量透射和克制表面补光形成细腻层次；重叠处密度增加，厚纸与手部保留可读的反射细节。
- 金属外观：按部位保留光泽、亮带边界、明暗过渡、纹理方向与尺度；布光依据该表面的反射表现调整。
- 纸与薄膜：透射密度、重叠区域、切边和厚度共同决定明暗。
- 蜡笔与颜料：用颗粒、手部压力痕迹、局部厚薄和透光孔隙形成色场触感。
- 手部动作：抓握、受力、接触和被遮挡区域符合该动作。

## 评审与下一步

打开参考与候选，先从用户请求和本 Skill 默认目标确定本轮应有的画面关系，再确认垂直俯拍、承载面与场景状态。原物对照来源外观；模型分别对照识别要求与当前成品设计，检查所选造型、尺寸、材料和制作关系。再回答：主张是否能直接看见，图稿对应哪项特征，辅助内容与主题的联系有何依据，视觉重量、疏密与参考摄影关系是否落实。按部位核对光泽和细节，文字与事实内容依资料确认。

构图层的问题采用原始素材重构。方向成立后的局部缺陷采用范围明确的编辑。每次评审写具体观察和下一动作，使用工程检查结论说明工程事实，使用像素观察说明视觉判断。
