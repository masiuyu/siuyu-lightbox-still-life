# 为本次任务建立视觉语言

用于开放桌面创作、参考驱动的风格选择、同题探索，以及用户要求不同成图有实质差异的任务。来源中的主体和保持项先确定；已有明确风格或局部修正时，直接采用相应决定。

开放构图和跨媒介时，选读 [观看目的与成像选择](restaged-print-world-editorial.md)。先明确要传递的认识、关系或感受，再联合决定空间、投影、图形信息与材料受光。用户指定的风格转为当前具体选择，来源启发及项目贡献见 [方法来源](method-sources.md)。

## 从观看意图连接各项选择

先用一句话说明观者要发现什么，例如材料的柔软、构件的紧张连接、透过界面才显出的形状，或一个符号在不同工艺中的变化。再决定哪些画面关系能把它做出来。

| 要做出的决定 | 怎样落实到当前图 |
|---|---|
| 形体语言 | 圆润、收尖、分枝、薄片、流动、线圈或规则单元分别发生在哪里；主体轮廓与必要连接怎样保持。 |
| 材料与状态 | 原物材质、当前新设计、加工或流动状态各有哪些依据；由哪类反射、透射、变形与边界形成主要观感。 |
| 研究表达 | 本轮研究整体、局部、材料或过程；采用图解、织样、压印、扫描式图面、透明叠片或其他合适媒介。 |
| 空间与构图 | 单体、并置、簇群、连续路径、环绕、层叠、切片或局部充满画面，怎样形成阅读顺序。 |
| 光与颜色 | 哪块亮暗、色场或反射承担主次；清晰、遮蔽、渐变与发光分别落在哪层。 |
| 边缘与密度 | 哪些地方硬、软、稀疏或密集；细节怎样随观看尺度出现。 |

这些决定共同形成一种观看方式。改变材料的柔软性，可能同时改变轮廓、接触、研究稿和显纹光；改变研究媒介，也可能改变底面、尺度及分组。只展开本轮相关关系，明确决定后直接写画面。

## 分清成品、介质与图面

实物、模型、承托和工具处于共同拍摄空间；玻璃、磨砂板、薄膜、水滴等介质改变后方内容的可见方式；图稿、印色、像素与示意图在各自图面中采用选定表达。分别说明效果属于哪一层、从哪里开始、在哪里结束。

例如，真实木件可以保有木纹和清漆，旁边研究片采用金属反射式的图形表现；透明包装可以有真实可见的内部，旁边示意图只展示有依据或本轮设计的构件；一张热成像式图稿可以采用伪彩，产品实体继续按当前材料受光。图面可以有自己的空间规则，载体仍按实际摆放与光成立。

参考为手机截图时，先定位嵌入作品的有效窗口。标题用于检索，具体外观来自作品区域的观察。讲解人物、播放器和界面信息保留在来源记录，成像说明指出选用的作品范围。需要裁取参考时依当前工具和授权另行保存副本。

## 用可见机制理解参考

下面的例子来自项目参考资料的逐图观察，提供选择关系。截图中的名称用于定位，当前任务按可见内容形成自己的实现。

- 镜面形体与网格、像素、窗口式图形相遇时，实体可依靠亮暗反射，图稿可依靠栅格与重复节奏。两种信息在各自层面支持同一主题。
- 发光颗粒、星芒和光束可以形成幻想图面的体量；柔软色场可以形成平面气氛。实体发光、镜面闪点与图像光晕按各自作用安排。
- 隔着带水滴或磨砂界面观看时，近处界面与后方主体可以有不同清晰度。遮蔽区域与清晰窗口决定观者怎样发现主体。
- 扫描式条带、重复片段、接触影像和技术爆炸图分别采用不同成像逻辑。研究表达应解释当前轮廓、装配、材料或过程。
- 木纹、线圈、绣线、蜡的流痕、枝脉和团簇边界可以直接形成字样与图形。材料参与造型，图面节奏随其结构生长。
- 微观网状结构、透视式内部显露和伪彩映射可以作为概念图像语言。实际内部、倍率和测量数据采用相应资料，艺术解释在工作记录中说明。

材料的具体落地见 [材料与过程](material-process-atlas.md)，研究内容与载体见 [研究表达](study-artifacts.md)。

## 让形式、空间与情绪形成联系

气氛来自可见组织。先选本张需要的张力、安静、轻盈、亲密或陌生感，再寻找当前主体适合的实现；同一情绪可以采用不同材料与明暗。

| 可用的组织关系 | 怎样落到画面 | 与其他选择的联系 |
|---|---|---|
| 放射与汇聚 | 尖形、条带或线向同一位置收束，以局部反差建立焦点 | 汇聚点可对应开口、动作或图形转折；发光边缘与柔软背景形成速度感。 |
| 连续软色场 | 大面积颜色缓慢过渡，保留一处相对清楚的小形或边界 | 局部结构承接辨识，颗粒尺度与色彩面积共同决定平静或迷离。 |
| 镜面与数字符号 | 清楚反射轮廓与像素、网格、窗口形图面建立对照 | 视点、分组及符号归属决定人工感；具体符号依据本轮主题设计。 |
| 颗粒与光点成形 | 用密度、轨迹与局部明暗聚成轮廓，周围留出呼吸空间 | 适合幻想或图面主视觉；粒子表现、实体发光与真实微粒各按所选范围判断。 |
| 标本与接触图面 | 借助薄度、脉络、重叠密度和近似平面组织细微差异 | 稀疏单体可以强调脆弱边缘，密集叠片可以强调遮挡和色密度；内容由当前主题选择。 |
| 规则与局部偏移 | 网格、同轴或重复单元建立参照，一处方向或密度变化成为发现 | 适合技术、材料对照与图形研究；需要真实比较时保留对应条件。 |
| 宏观与微观切换 | 让孔隙、分枝、线圈或颗粒成为画面的大形 | 构图的主体随尺度改变，原来细节的密度与边缘现在承担主次。 |
| 超常尺度与场景并置 | 在艺术图面内改变物体相对大小或安置关系，形成明确视觉主张 | 物体形状与场景线索支持辨识；载体内的幻想空间与外部实物空间各有范围。 |

这些关系可用于摄影、图面、插画与混合媒介。先选主导关系，再决定其他关系怎样支持它。新题材可以重新组织画面，当前要保留的产品身份、图面窗口和准确文字继续明确。

## 发展同一任务的不同方向

开放探索先比较确有不同观看目的的想法。例如，同一开口圆环可以研究“线材怎样围出空隙”“镜面怎样显出弯曲”“凝固材料怎样留下负形”。它们会分别改变研究件、材料、空间密度、光与边缘。方向数量按任务需要，实际生成范围遵循授权。

选择理由说明当前主体为什么适合这条路径，以及哪项困难需要解决。产品材质或形状已锁定时，变化可来自研究媒介、背景、机位、图面和光；新概念的材料选择在允许范围自主展开。明确采用一个方向后，用其主张组织辅助内容。

## 让系列有联系，也有发现

先说明系列要延续的关系，例如同一符号、共同阅读顺序或一类材料研究；再给每张选择自己的材料机制、研究表达与空间。需要严格一致的产品系列，按锁定条件延续；需要多方向探索的任务，分别记录各方向新增了什么观看经验。

比较实际画面时，先遮住标题和风格名称，看轮廓、视觉重心、明暗分区、媒介痕迹、材料及空间是否呈现选定差异。若变化主要停留在色相或主体替换，回到本轮尚未落实的设计决定。具体身份与系列判断见 [风格迁移](style-transfer.md)。

## 写入方向与评审

工作记录简述意图、有效参考、所选媒介、材料与空间之间的原因。成像说明只写最终画面：对象怎样形成，研究内容附着在哪里，光和颜色如何使它们可见。

评审同时判断主张是否可见、身份是否符合任务、材料与图面是否各有清楚归属。要求多样性时，将实际差异单列观察位置；实际图片提供视觉证据，文字方案只提供设计决定。[创作调用](creative-orchestration.md) 连接后续模块与修正路径。
