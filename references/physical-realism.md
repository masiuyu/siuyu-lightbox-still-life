# 全场景实物真实性

一幅静物中的主体、模型、纸张、图稿、承托、工具和道具共享同一拍摄空间。每件物品都需要由它的体量、边缘、材料、连接和光响应解释身份。风格化模型按当前选择的造型与工艺判断。

## 按当前表现方式确定核心项

实物摄影检查体块、材料、支撑和共同光场；平面艺术图面检查指定图形、色场、边缘、媒介及画幅。图中表现了实际纸墨或实体层次时，再检查它们的物理关系。概括、夸张和空间处理以当前明确选择的表现方式为准，必要身份与用户保持项继续参与判断。

按 [观看目的与成像选择](restaged-print-world-editorial.md) 先确定本张要看懂的关系，再用相应证据观察：摄影看构造、光与接触，绘画看所选投影和活动联系，结构图看连接与遮挡，印刷看分色及载体，原照保留看实际映射。叙事线索采用当前来源或明确的创作范围。

混合媒介中分别检查实体、相机前的介质及载体内的图像。屏幕、薄片或印面中的扫描拖曳、假色和透视图形按本轮图面设计判断；其边框、厚度、支撑和对周围光的作用按实体判断。选择性展示内部的概念图，其可见结构需要按来源依据或本轮设计范围说明。材料形成与图像表现的区别见 [材料形成](material-process-atlas.md)。

先按整体观看大小检查主张、第一落点、色块、视觉重量、信息密度和空间，再按主体及原生尺度检查材料观感与必要细节。[视觉层级与 Smooth Control](visual-hierarchy-smooth-control.md) 将整体组织、真实摄影和材料保真共同列为观察。不同媒介的系列对照所选共同关系，各自按本张目标评审。复杂任务的具体返回路径见 [创作调用](creative-orchestration.md)。

## 先决定每件物品怎样存在

对重要物件用一小段回答：它是什么实体，多大，由什么材料构成，怎样连接，以什么朝向放在哪里，与什么接触，受什么光。相同纸种或做法可以合并；有明显表面差异的部位分别描述。

原物保留来源结构与材料。新建模型先选择识别特征，再设计成品高宽长、主次体块、细节和制作方式。勺碗与柄、杯口与壁、把手与连接要能解释器物功能。模型、纸张、工具和手各按自己的实物尺寸建立关系，镜头占比由取景决定。

制作痕迹取决于所选工艺和成品质量。植绒有明确芯体与短纤维覆盖，针毡由压实纤维形成体积，彩绘模型分别用起伏与色区表达结构，玻璃用厚度、边缘与透射解释体量。复合材料检查基材、表层及其相遇方式；各层起伏、反射和透过内容按选定构造相容，具体观察见 [构造案例](material-construction-cases.md)。主要轮廓、局部细节和表面共同支持同一种制作方式。

## 纸层、图稿与接触

图形属于指定媒介，随其旋转、弯曲、遮挡和光改变。木刻随木件形成深浅与收边，绣线依附底布并保留线迹，蜡印有相应厚度与正负形，透明片按边界和叠层显示内容。选用完整纸张时检查完整边界、薄厚和柔韧性；纸层覆盖既有笔迹时追踪同一线条在两侧的变化。具体观察项由本张采用的媒介确定。

纸面扫描变形、透视、微光、X 光式结构及伪彩检查各自图像窗口与研究目的；纸张另查实际透视、材质、接触及场景受光。图像内的光效与纸外照明按本轮选定光路分别核对，具体方法见 [研究媒介](study-artifacts.md)。

物件的承力点、遮挡和接触连续。光台与柔光可以形成浅接触影，物件仍应由边缘、局部明暗或形变说明落地。俯拍下可见侧面需要结合摆向和高差判断。反射、透射、投影与对焦分别承担对应作用。

## 成图判定

先仅依据用户要求与原始来源列出应有目标、对象、部件及载体，再与方案和成图比较。全图先看观看顺序、主体辨识、完整轮廓、画幅、台面与留白；随后以原生尺度检查必要细节。

核心观察覆盖以下实际关系，按本轮对象合并或细分：

- 本轮希望发现的关系在明确位置可见，研究图或样片确实解释相应主体特征；比较任务保留足够稳定的参照，系列在各自画幅中保留约定的共同关系。

- 整幅画面的第一落点、大形、块面、空间与细节密度共同支持本轮观看任务、表现媒介和光路，真实摄影保有当前人物、材料、接触及环境的必要线索。
- 主体身份、数量、稳定部件、各图面内容和边界符合来源与任务。
- 模型实现选择的体量、成品尺寸关系、工艺、材料和必要连接。
- 机位、摆向、尺度、支撑、遮挡和接触能够在同一空间中成立。
- 每类辅助物件有相容的材料、边缘、纹理和光响应。
- 纸层与图稿附着正确；印刷面采用指定工艺和墨层；相关细节在要求的观察尺度可读。
- 实际原生宽高、完整取景、物件分组和连续桌面符合交付要求。

观察先写所见，再对照要求给结论。通过需要可见证据；需要修正指向具体矛盾；待确认指向看不清或证据不足的位置。隐藏加工、材料配方和校准实测数据按各自证据另行说明；关键可见承托、工艺和连接继续参与核心判断。

回读执行前的关键预期，检查它在指定位置是否成立。新发现单独保存，对原因的解释按其证据范围表达。主张、材料和完整性全部成立时，精修按当前反馈选择；后续改动的取舍见 [创意判断](creative-judgment.md)。

独立生成近景时，按其自己的方向、原生图片与材料关系评审；对应全图的细节用该图实际像素检查。近景与全图的主体对应须可辨认，二者的验证状态分别保留。

发光体检查发光区域、外壳、受光邻面及遮挡的相容性；处理后的图片检查指定阅读区、识别色和材料差异。纯白或纯黑区域按本张任务判断，具体阅读目标见 [成像处理](image-development.md)。多机位与视频分别检查实体空间、当前投影及实际接续，见 [机位与运动](camera-and-motion.md)。

## 观察要对应本次要求的形成机制

核心项从用户用途和来源中选择。概念影像检查归属、投影、层次和指定表现是否可见；产品保真检查来源的形状、材料及识别内容；真实测量或制造确认按任务选择对应记录。隐藏物理参数与当前可见任务各自说明依据。

对每个重要机制，选一个能把它与其他解释分开的观察位置。内部显影看外轮廓的包围、内部密度与周围结构共同成像；透光材料看厚薄、边缘、透过内容和受光关系；刻印看痕迹内壁及其收边；局部调色看指定色区和邻近保持项。要求的关系清楚成立时才通过，出现可辨矛盾写需要修正，看不清时写待确认。

评审先对照请求和真实参考，再与本次方向核对。检查变更目标，也比较一处邻近保持项和全图主次。新的观察可以修正判断，计划中的描述本身继续属于预期。

## 从观察选择下一次修正

先区分三种情况：当前画面呈现了与核心要求相反的关系；需要的关系因面积、焦点或反差不足而无法判断；目标已经可见但有可选精修。第一种指向具体结构或材料修正，第二种先改善观察条件，第三种沿用户要求选择是否继续。把可见矛盾写为需要修正，把证据不足写为待确认。

选择下一动作时说明想改变哪项关系，以及什么观察能支持它。反光增加了但墨层仍读成同一种构造时，继续回到层序与边界；扩大视图后才能追踪的纤维，先用合适原生面积观察。效果与预期不同的原因可以保留为假设，下一张图片按实际授权执行。

不透明覆盖层下的隐藏部分按工艺说明和可见接续推断；原生图片评审指向实际可见的端点、收边、相邻底层与表面响应。实物加工层序的确认另需相应生产证据。新小样的成功与原全图的状态分别保存，迁回全图时复查原有构图、颜色和连接。

## 验收记录与状态汇总

使用普通 Markdown `review.md`。在 `## 核心观察` 下记录四列表格：检查位置、实际所见、应有结果、结论。结论写“通过”“需要修正”或“待确认”，也接受 PASS、REVISE、UNVERIFIED。样例见 [评审文件](../assets/review.example.md)。

有任一需要修正项，总体需要修正；其余通过但仍有待确认项，总体待确认；全部核心项通过，总体才通过。可选精修放在其他段落，核心要求仍由用户任务、来源和当前制作决定。若写出“总体：……”这一行，必须与核心表一致。

```bash
python3 <skill-dir>/scripts/lightbox.py review /path/to/review.md
```

脚本只核对记录与汇总，观察真实性和覆盖完整性由看图确认。既有 generation-record.json 仍可用 validate_image_review.py 复读。交付说明、评审和执行记录采用同一总体结论，用户接受另依据用户表达记录。停止成像保留实际视觉状态。

需要把本次调用、原生图、裁区和评审连接起来时，使用 [图片证据](image-evidence.md) 的留存与复核命令。它们核对记录和原生像素对应，视觉结论仍来自上述实际观察。
