# 全场景实物真实性

用于每幅光台成片的设计与看图。画面里的主体、模型、承托、纸层、图稿、工具、包装和其他道具，都按其本轮身份表现为同一现场的真实物件。手办与造型物可写实、概括、夸张、单色或透明；真实性落在所选物件的成品尺寸、形体、制作材料及摄影表现上。

## 先决定物件，再描述画面

先按 [来源关系与呈现范围](object-relations.md) 明确哪些内容在本轮成为实体，以及各自的来源和任务依据。再把选用物件逐类列入现有方向记录，每件回答：**是什么实体、怎样构成、由什么材料制作、多大、以什么姿态放在何处、与什么接触、受什么光**。同种纸张或相同工艺可合并记录；不同主体和具有不同表面的部位分别说明。

| 检查对象 | 设计时明确 | 成图应能看见 |
|---|---|---|
| 原物与主体模型 | 固有部件与身份；主要体量、成型、分件连接、厚度、重心和朝向 | 连贯的整体轮廓与体块；开口和连接具有结构；模型工艺通过整体形体与局部处理共同可读 |
| 主体和道具的材料 | 表面处理、边缘、纹理方向与尺度、透明度、柔软度及材料连接 | 同一材料内部表现连贯；不同材料在边缘、形变和光响应上有可辨差异 |
| 纸张、照片和图稿 | 纸种的可见外观、薄厚、层数、折弯、绘制或印制方法以及内容所在层 | 图线附着纸面；纸边、交叠、局部翘曲与遮挡连续；内容随纸层与照明变化 |
| 底座、衬垫、支撑和工具 | 各自尺寸与做法、承力点、接触面、接合、握持或放置方式 | 物件放得稳；受力与材料形变相容；承托与被承托物的边界能对应 |
| 全场摄影 | 一个明确机位、相容尺度、主辅光方向、反射环境和必要清晰范围 | 物件共享同一空间；接触、遮挡、投影、高光和清晰变化共同解释摆放 |

目标尺寸由操作者按 [实际手办尺寸参考](model-construction.md#手办成品尺寸与缩尺)、选定工艺和构图确定。每件模型先写成品高宽长，必要时再计算相对原型的缩尺；底座、纸张、工具和手有各自的实际尺寸。它们在同一台面中的相对大小应可信。纤维、浮雕、分件与纹理服从各自模型的物理尺寸，交付取景让关键线索可读。

## 现实器物的完整结构

器物先按现实类别确定可用轮廓、开口、容腔、连接和厚度。勺碗、颈部与柄共同形成连续金属器具；杯口、杯壁、杯底和把手共同解释容器。透明器物的折射与反光沿同一结构变化，细节尺度跟随整个物件。

材料样件采用与工艺相容的切边、厚度和表面；纸样保持可读边界和合理纤维尺度。食物题材先确定现实品种、完整形态、成熟状态与普通加工方式，再让外皮、切面、内部组织及容器接触共同支持辨识。模型按当前来源和造型目标建立同样清楚的实体依据。

## 让模型像实际做出来的物件

按 [模型建构](model-construction.md) 先选择所需辨识与造型取向，再从整体体量开始。用一句话说明体块和局部比例怎样服务所选表达，再说明材料怎样形成这些形状、次级结构怎样连接、细节怎样制作。每件模型选择连贯的工艺；混合材料明确使用部位与连接。

细节分为影响轮廓与体积的结构、表现身份的浅层起伏、涂装或印刷的色区。按当前主体分别归类。植绒明确芯体与覆盖的短纤维层；针毡说明压实体积与束向；打印彩绘说明几何起伏与绘制分工；玻璃说明体量、厚度、透明度与光响应；片材说明折叠、层厚与接合。近看与整体观看应支持同一种制作方式。

真实做工的精细程度由目标产品决定。精密物件可有平整表面和隐蔽接合，手作物件可有适量的制作痕迹；采用真正适合该工艺的线索。让观察者从形体、厚度、细节尺度和材料响应共同判断实物身份。

模型识别面需要朝向上方镜头时，选择实际可摆放的朝向、平背构造或承托方式。主体、底座和支撑采用一致的旋转关系；整件物体的上表面、侧面、接触点与受力应能同时成立。

## 让周围物件同样真实

纸张具有自己的厚度、切边、柔韧性和遮挡。图稿采用与纸面相容的石墨、墨迹或印刷外观；线条与文字沿纸面弯曲、透视和层次变化。只表现本轮指定的画面内容，事实性文字采用准确来源。

薄半透明材料按厚度与交叠产生不同透射密度，下层内容随覆盖与层间距离改变可见程度。反射、透射和景深各有对应作用：纸的散射、表面的亮带与镜头的离焦分别描述。柔光下保留足够信息，让不同纸层、表面和物件边界可辨。

硬物、软物、食物、包装、植物与工具各按所选对象的实际属性安排边缘、弯折、压缩、容纳和承托。新增道具先确定具体物件身份和构造，再决定它贡献的形状与色块。辅助内容沿当前主体形成有依据的联系，并以自己的完整实体进入画面。

## 在同一台面建立光和接触

默认相机垂直俯拍，必要识别面通过物体朝向展示。判断机位时同时看主承载面、纸边、物件高差和各自摆向；立体物件在俯拍中可以显露侧面。

对每件实体说清接触点或接触面，遮挡顺序与承托连续。光台底光可以减弱部分阴影；根据当前光面、物体高度和材质决定阴影深浅，接触仍应通过边缘、遮挡、局部明暗或形变可读。支撑与受力同时可解释。

材料响应由 [光路设计](lighting-optics.md) 与 [部位材质](material-color.md) 决定。光滑、粗糙、金属、纸张与透明材料可以共享光源，但各自的反射、透射和纹理保持区别。投影、亮带、暗反射和颜色反射的位置共同支持这个光场。必要清晰表面与离焦按其空间位置分配。

## 成图判定

先仅看原始来源与用户请求，重新列出应有的完整视觉目标、对象、稳定部件及载体，然后再与作者方案和成图比较。要求采用当前用户目标、原物结构，以及适用的 [默认视觉目标](../SKILL.md#默认视觉目标) 与主体范围。先在交付尺寸检查整幅画面是否成立，再检查实体重量、空间和材料，最后放大主体与关键道具检查边缘、结构、接合和纸层。每项先写实际观察，再给结论：

`位置 / 所见：……；要求：……；结论：PASS、REVISE 或 UNVERIFIED。`

核心项包括：

1. 单列完整视觉目标检查：默认方向在交付尺寸下能辨认主体与研究材料的具体对应、透光与实体的层次，以及完整的共同俯拍构图。根据实际物件指出各项证据；用户明确选择其他目标时按该目标逐项检查。
2. 任务所需的个体、对象类型或主题能被辨识，数量与用户明确的特征要求对应。现实器物的功能部件、轮廓、开口和主要连接在整体尺度清楚成立。
3. 单列来源范围检查：以原始来源和当前任务独立列出的对象、部件、边界及图稿内容为要求，逐项比较成图中的全部实体、图面和样片。模型研究图与造型样片和主体共用部件清单；材料样片对应选用的制作材料；完整照片和指定场景图各有用户明确的内容要求。所表现内容按原始类别核对采用依据，边界与周围应露出的表面一同检查。例如张口雕塑的实体在口沿结束，口前连续露出光台，研究图在对应位置露出纸面。每一项由来源结构或明确用户目标支持，再单独检查制作方式与承托。
4. 模型实现选定的造型、成品尺寸、体块、细节和制作方式。
5. 机位、物件摆向、尺度、连接和承托能在同一空间中成立。
6. 主体与每类辅助物件都具有与其构造相容的材料、边缘、纹理和光响应。
7. 纸张、图稿与实物之间的附着、交叠、遮挡、透射和接触关系连贯。需要呈现下层笔迹柔化时，覆盖区域与真实笔迹相交，能指出同一笔迹在边界两侧的可见差别。
8. 单列整体构图与交付画幅：记录实际像素；主体主次、必要轮廓、辅助材料分组、留白与连续台面逐项符合本轮要求。默认完整静物的四边和四角为连续桌面，动作场景按指定握持位置呈现手腕。

`PASS` 要有满足要求的可见证据；`REVISE` 指向具体矛盾及需要改动的决定；`UNVERIFIED` 表示关键处不足以判断，需要更合适的取景或补充观察。内容采用的依据须能回到原始请求、来源结构或上述默认范围；候选提案、制作可行性与先前评审各按自己的用途记录。成图内容与这份范围存在差异时，范围核心项记为 `REVISE`。整体达到要求以核心项全部通过为条件。

按来源与任务确定内容关系及范围检查，再按所选方案确定制作检查；成图中新出现的实体关系也按同一标准检查。载体、实体范围、所选制作工艺、可见连接与承托都属于核心要求。可选装饰精修、用户审美接受、内部材料配方与独立测量放入附加记录。隐藏加工细节只限制对应的制造判断；当关键承托不足以解释可见稳定关系时，承托仍属于核心项，按实际证据记为 `REVISE` 或 `UNVERIFIED`。

作者检查与独立审查采用相同标准。调用成功、参数齐全或方案通过，只记录其实际完成的阶段。修正次数达到上限时，保留当前版本的实际视觉状态。用户审美接受只依据用户表达。

## 验收记录与状态汇总

在现有 `generation-record.json` 的 `visual_review.core_checks` 中保存核心项，每项写 `position`、`observed`、`requirement` 和 `conclusion`。由这些结论统一确定 `visual_review.overall_status`：

| 核心项的实际结论 | 总体状态 |
|---|---|
| 任意一项为 `REVISE` | `REVISE` |
| 其余均通过，仍有 `UNVERIFIED` | `UNVERIFIED` |
| 全部核心项为 `PASS` | `PASS` |

核心项须覆盖本轮要求，列表应包含实际检查结果。附加观察放在 `additional_checks` 或单独的说明中；核心项的归类沿用上述要求。评审文件、生成记录与最终交付的总体结论使用同一汇总，修正项逐一保留。停止继续成像只结束执行，不改变当前图片的验收状态。

保存后运行 [验收记录校验](../scripts/validate_image_review.py)：

```bash
python3 <skill-dir>/scripts/validate_image_review.py /path/to/generation-record.json
```

脚本只读取记录，检查状态名称、核心项列表和总体结论的一致性。它兼容既有的 `object_checks`、单项 `status` 与汇总 `core_status`；既有 `object_checks` 整组参与汇总，一个记录采用一组核心检查列表。记录不一致时，依据实际观察修正相应判断或汇总，再运行校验。

输出中的 `record_consistent` 仅表示记录自洽，`overall_status` 才是该图的总体状态。核心项覆盖、观察真实性及材料和连接是否成立，继续由实际看图判断。存在核心修正项的记录可以自洽，其总体状态仍为 `REVISE`。
