# 来源关系与本轮呈现范围

用于每个提供内容的输入，包括首次上传、既有成图、重新上传、局部编辑及载体转换。先从实际图片建立对象关系，再根据当前任务确定呈现范围，随后选择造型、材料和承托。简单物件用几句即可完成，重点记录会影响主体归属、动作、载体或编辑范围的元素。

## 先读原图中的关系

先在全图中辨认用户所指的实体对象，再查看会影响其轮廓和部件归属的区域。对每个区域分别记录“是什么、与主体发生什么关系、可见证据是什么”。物件名称可以包含功能、地点或主题，组成判断继续落实到实际物件与部件。按以下关系取证：

| 关系 | 识别依据 | 对当前范围的作用 |
|---|---|---|
| 本体组成 | 物件或身体的连续形体、内部开口、实际表面，以及可确认的结构接合 | 形成主体部件清单 |
| 装配、穿着或附着 | 接合位置、固定方式、穿戴关系及原物或配件说明 | 按实际归属记录附件；现成造型物按其真实构造处理 |
| 握持、承托或容纳 | 分属不同对象的边界、接触、受力和容器范围 | 分别列出主体、承托物、持物或内容，再决定用途 |
| 产生、流动、燃烧或其他作用 | 起点、介质形态、运动路径、扩散边缘及作用终点 | 记录来源中的过程；按用户指定的场景目标选择呈现方式 |
| 照射、投影或映照 | 产生者、承接表面、光线和图像之间的关系 | 记录光学现象及其所在表面 |
| 绘制、印制或屏幕呈现 | 内容所在的载体、图面边界，以及图面内外各自的对象 | 按当前指定图面确定保留内容 |
| 并置或遮挡 | 前后位置、间距、重叠和能够确认的接触范围 | 按各自物件身份记录，连接未明处保留未确认状态 |

对同时接触主体的不同内容，分别寻找组成证据与作用证据。开口、喷口、灯具和运动构件各有自己的实体结构；从它们产生或经过的介质、光学现象与运动痕迹按作用关系记录。连续的画面轮廓只提供位置线索，归属判断还需要材质边界、接合或作用过程的证据。

再做一次状态变化检查：想象设备停止运行、人物结束动作，或对象离开拍摄背景，判断哪些部件仍然属于该对象。肢体与服装的姿态可以变化，其组成和穿着关系继续成立；来源中的过程单独记录。通过这项检查后，以部件名称写出模型范围，再从中选择辨识特征。

来源与目标的判断顺序保持明确：先识别来源内容属于实体、附件、过程还是图面，再决定本轮用途。表现某个过程的定格造型仍按场景内容确定采用依据；其制作材料在该场景目标成立后选择。用户以原物身份提供的现成造型物，依据它自身的实际材质边界、装配与来源说明确认构造。

来源是插画、渲染图、合成图或摄影时，分别记录其表现的关系和能确认的实物信息。图像表现出某种活动，可以支持对该活动的理解；实际材料、装配方式或隐藏结构按可见证据和来源说明判断。证据不足时指出具体未确认之处，并让目标方案采用有依据的范围。

例如，以狮首鱼身雕塑为主体，实体清单可按来源列为：狮首的眼鼻、上下唇、口腔和鬃毛，鱼身的鳞片与前鳍，尾部卷孔；下方台座依据接触与归属单列。口腔收在上下唇围成的开口内，实体在口沿结束，口前连续露出光台底面。模型与新绘制的研究图共用这些轮廓和纹样，研究图在口沿外露出纸面。对于其他对象，使用相同的关系判断，按实际可见部件建立各自清单，并写明关键部件的终止边界及周围表面。

## 再决定哪些内容进入本轮画面

先从用户请求确定本轮是在呈现对象、完整图面还是明确指定的活动场景。只上传图片并要求生成时，采用主体对象的台面静物作为默认目标，并在记录中说明采用了这一默认选择。按以下依据安排内容：

- 原物及既有模型按其保真范围保留实体结构、装配配件和外观。原物说明与实际可见连接共同提供依据。
- 从来源新建单体模型时，用有限的对象和部件清单写明实体范围，再自主设计成品尺寸、比例、姿态、材料和配色。新绘制的主体研究图与造型样片共用这份清单，采用对应的轮廓、结构和表面细节。制作材料样片以当前选用的材料为研究对象，比较其厚度、肌理、颜色或透射。
- 用户要求呈现活动、运转或复合场景时，按该场景范围安排参与对象与作用关系，并选择实际活动、模型造型或图面记录等呈现方式。
- 用户明确要求采用完整照片、画稿或屏幕图像时，内容属于相应图面；图面外的主体和道具各有实体身份。主体研究任务中的新绘图沿用主体部件清单。
- 局部编辑沿用已确定的范围，重点判断编辑区域及与其直接相接的关系。此前明确接受的内容按其确认范围保留。

主体部件以来源中的稳定结构和实际归属为依据；整个活动场景以用户明确要求的场景目标为依据；独立道具以自身对象身份、用途和搭配贡献为依据。逐项归入对应类别后再设计制作条件。模型姿态由身体、部件或服装自身的造型表达；工艺实现这一实体范围。

这份分类约束画面中的全部新增内容。图稿与造型样片按其描绘对象归类，材料样片按当前选用的制作材料归类，工具、器皿等道具按自身对象身份和实际用途归类。所表现内容的来源类别贯穿各种载体和摆放位置；表现来源过程的图形与造型均归为 `scene_content`，其采用依据落实到用户原话中的场景要求。每个候选先通过这项范围判断，再比较识别价值、审美贡献和制作条件。

以石雕对象为例，部件清单由雕刻体量、开口、纹样及实际基座归属组成；新绘制的研究图与造型样片据此展开外轮廓、局部纹样或部件关系。材料样片比较所选石膏、陶瓷或树脂等制作材料的表面与透射。完整原始照片和现场研究图各依据用户明确的内容要求确定范围。每张图稿在 `target_scope` 中写清研究的是主体模型、指定完整图面，还是指定场景。

对每个拟加入主体的部分，具体回答它表现什么、在原始来源中属于哪个对象，以及当前请求为何需要这部分。把来源中的归属依据与本轮计划的制作连接分别说明。将结论写成可见的部件边界；范围判断成立后，识别价值、材料和承托共同决定其做法。

## 写入输入记录

在每个 `subject`、`support` 和 `edit_target` 输入中填写 `content_analysis`，包含以下三个文本字段。纯风格 `reference` 通过 `use` 指定用途；需要进一步解释其内容范围时也可填写同一结构。

| 字段 | 写什么 |
|---|---|
| `relationships` | 逐项写对象或区域名称、组成／装配／承托／产生／图面等关系类别及可见证据；来源中的实体、过程与未确认部分分别说明 |
| `target_scope` | 以对象和部件名称列出本轮主体、独立道具及各张图稿的研究内容；模型研究图与主体共用部件清单，完整图面和指定场景各写明范围 |
| `basis` | 当前请求采用默认主体目标，还是明确指定原物、完整图面或活动场景；逐项给出来源中的归属依据或对应的用户要求，再说明独立道具的用途 |

例如，用户以杯子为主体时，可以这样记录来源中的承托关系：

```json
"content_analysis": {
  "relationships": "杯把与杯身通过两处接合相连；托盘位于杯底下方，作为独立物件承托杯子。",
  "target_scope": "完整杯子作为台面实体主体；新绘制的杯形研究位于旁边的描图纸上。",
  "basis": "用户指定杯子为本轮主体，杯身、杯口和杯把提供身份依据；纸面研究用于观察这些轮廓。"
}
```

先完成这三个字段，再提取同条输入的 `preserve`。`decisions.subject_basis` 汇总各来源的目标范围；材料与搭配按照这份范围展开。旧方向再次编译时，为本轮实际查看的输入补齐当前判断和 [内容范围契约](prompt-execution.md#选择记录契约)。`subject_study` 使用上述默认选择；`explicit_scene` 与 `explicit_image` 的依据分别对应用户明确要求的场景内容与完整图面。

完整观察、关系分类和范围依据留在方向记录中供复查；对应输入的 `use`、`target_scope` 和 `preserve` 用正面语言描述本轮采用的内容，并进入提示词。编译器检查记录完整性、内容范围与选中候选的类别相容性；来源分类和用户依据的真实性由原始资料对照确认。

## 用原图检查方案和成图

生成前先仅看原图与用户要求，完成上述关系分类和状态变化检查，保存对象、部件及载体的来源结论；随后再读方案中的 `relationships`、`target_scope` 与 `basis`，逐项比较。每个模型部件对应明确的组成或装配依据，独立研究与搭配材料对应自己的用途，场景造型对应用户原话中的场景要求。采用独立审查时，审查者先形成这份来源结论，再接收方案。主体范围由这次比较确认后，继续检查 `preserve`、搭配、材料和验收目标。

在 `review_targets` 中加入本图具体的来源与范围检查，例如杯子由对应的杯身、杯口和杯把构成，杯形研究描绘这组结构并附着在独立纸面上。生成后先依据原图和请求重新判断应有范围，再比较成图中的每件实体、图稿与样片。范围核心项逐项写出应有部件、边界和周围应露出的表面，并将方案中的全部新增项纳入比较；归属结论由原始来源或明确任务支持，制作检查随后单独进行。发现范围差异时记为 `REVISE`，回到当前任务重定方案并重新编译。
