# 方法来源与项目贡献

本文件用于维护研究归属和发布准备。实际创作依据当前用户请求与本项目的 [观看目的与成像选择](restaged-print-world-editorial.md)、材料、光、摄影及执行方法展开；原项目的名称用于标明具体研究来源。

| 来源与固定提交 | 研究得到的具体启发 | 当前承接及贡献范围 |

| [yanliudesign/mono-color-skill](https://github.com/yanliudesign/mono-color-skill/blob/c8ff70597ddedcd65f21a0b528f6a70c35690b0a/SKILL.md) | 编辑主次、印版分工与纸面明暗之间的联系 | 本项目沿已有印刷与载体方法选择实际分色，并用扣件装配方向准备信息阅读验证；具体版面依据当前内容发展 |
| [fihaaade/skills — outsider-art](https://github.com/fihaaade/skills/blob/1aa85f4a0f426e985659b202efb33c3f7e01e48c/outsider-art/SKILL.md) | 场所区域、绘画投影、人物活动和密度需要共同组织 | 本项目按活动关系选择分组、投影与媒介。当前温室采用纵深、透明水彩和工作交接，已附当前样张与可见评审，后续任务继续检查实际效果 |
| [ZzzLc0405/photo-abstract-editorial](https://github.com/ZzzLc0405/photo-abstract-editorial/blob/49e55073d6d0330274d31f75d27f5dd6eb35fd6d/SKILL.md) | 照片内容的保留与关系提取各有明确任务，抽象表达需要可说明的内容依据 | 该研究启发纳入资料用途与图形信息判断。本项目已有自然语言接口、局部编辑及映射验证分别承接当前任务；照片与抽象回应的专门流程继续归于原来源 |

当前指南以观看目标、身份、空间、图面信息、材料与光之间的依赖组织选择。自然语言任务传递、原生图片与评审对应及既有印刷模块属于本项目实际执行体系。当前交付包含任务关系指南、调用接入、归属说明、文字方向与实际样张；真实成图表现按各次实际产物判断。
