# 从材质目标到光路

在现有摄影设定中完成这项判断：**关键部位要看见什么 → 由哪种光学作用形成 → 怎样布置有效光面与遮挡 → 图片里怎样确认**。选择本轮实际涉及的表面；每个光面承担明确作用。同一灯与反射卡可共同完成多个作用，所需灯数由场景决定。

## 按表面与观看目标选择

先用 [材质证据](material-color.md) 确认外观、涂层、纹向和曲率。下表提供有条件的布光起点；具体位置随机位、产品形状与表面证据调整。

| 表面与目标 | 光路与控制 | 应保留的可见证据 |
|---|---|---|
| 抛光金属，读曲率与金属色 | 将中性亮面放入关键曲面的反射方向，邻接可控暗面；调整反射带形状、宽度与渐变。 | 明暗带随曲面转折，棱边清楚，有色金属仍有可读色密度。 |
| 细拉丝或方向性光泽，读工艺 | 按实际纹向选择条形或大面反射的方位；细纹和高光延展共同说明表面。 | 方向与尺度符合来源，抛光边缘和拉丝大面各有光响应。 |
| 清漆、釉层、亮膜，读表层与底色 | 设计表层反射带，同时为下方纹样、标签或木纹保留阅读区。 | 光泽与底层信息同时可辨；不同表面区域保持各自层次。 |
| 清澈玻璃、透明塑料或液体，读透明度 | 背景透射确定内部色密度；反射卡或遮旗定义容器边缘；标签按需获得局部前光。 | 壁厚、液面、边缘与内部层次共同成立，表面反射随形状和视角变化。 |
| 磨砂、半透明纸或散射体，读厚薄 | 背光形成透射层次，克制表面光呈现纤维、磨砂或实体边界。 | 透射密度符合厚度和材料证据；散射柔化与对焦范围分别可读。 |
| 哑光、压纹或粗糙表面，读本色或凹凸 | 本色优先用适量侧向面光；凹凸优先按纹路方位选择掠射光，再调必要填影。 | 本色、细纹尺度和微阴影支持本轮观看重点。 |
| 多切面或闪点表面，读结构与闪耀 | 大面光维持主体与镶嵌信息，小面积光只服务选定切面；明暗环境共同组织切面。 | 少量闪点与可辨切面、颜色和连接结构并存。 |

反射与透射可在同一界面共存，并随观察角度变化；材料内部还会吸收或散射光。按表层、内部、厚度与几何分配表现。丝缎、绒面和珠光的方向变化，依据来源中可见的光泽与色晕单独描述。[介质界面](https://pbr-book.org/4ed/Reflection_Models/Dielectric_BSDF) · [金属界面](https://pbr-book.org/4ed/Reflection_Models/Conductor_BRDF) · [粗糙度与方向性](https://pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory)

## 把光写成可执行的几何关系

- **有效光面**：写物体实际看见的亮面形状、长短方向、相对大小、方位和亮度渐变；扩散面应按设计被照亮。尺寸未知时用相对主体的覆盖和反射范围描述；有尺寸依据时再写灯至扩散面、扩散面至主体的距离。
- **反射路径**：固定本轮机位，按目标部位的局部曲面判断哪个亮面与暗面会被镜头看见。白卡提供亮反射或补光，黑卡提供暗反射或吸收环境填充；在提示词里说明实际用途。[反射面布置实例](https://broncolor.swiss/news/how-to-photograph-a-glossy-object-bottles)
- **投影与反射分别描述**：光源的角尺寸和主体至承影面的距离影响投影软硬；光滑表面可同时映出边界清楚的大光面。明确接触影的方向与过渡，以及产品亮带的边界与形状。[光源尺度与投影](https://broncolor.swiss/news/hard-soft-and-diffused-light-what-is-the-difference)
- **纹理方向**：擦光角以局部表面为基准，入射角以该处法线为基准；写数值时注明基准。方位要服务压纹、纤维或拉丝的实际方向，曲面按关键部位判断。

## 颜色与偏振按目标启用

产品本色优先由适合颜色呈现的中性白光承担，背景或辅助色按 [配色关系](material-color.md) 分配。灯光光谱、材料响应、相机响应与白平衡共同影响颜色；色温描述白光冷暖，色谱评价还需各自的参考与测试条件。生成任务把产品色、透射色和环境反射写清楚；真实颜色校准依据实际灯、样品与相机记录。[光谱与相机颜色](https://www.oscars.org/science-technology/projects/spectral-similarity-index-ssi)

偏振用于需要增强图案或颜色可读性的区域，先判断目标光泽是否仍应保留。镜头偏振的作用依赖入射光与反射几何；交叉偏振还包含光源端与镜头端的配合。塑料应力、显示屏和复合涂层分别评估其响应。真实拍摄需比较滤镜前后的光泽、色偏与光损；生成图用可见的反射变化验收。[偏振应用与限制](https://www.edmundoptics.com/knowledge-center/application-notes/illumination/successful-light-polarization-techniques/)

## 复用已有提示词字段

| 现有字段 | 本轮写入的决定 |
|---|---|
| `design.materials[].light_response` | 具体部位需要的光泽、反射边界、透射密度或纹理响应。 |
| `photography.lighting_setup` | 实际选定的光面、位置、相对尺度、反射卡与遮光分工；选择偏振时写明目标区域及保留光泽。 |
| `photography.exposure_intent` | 哪些透射颜色、高光、文字和暗部优先保留，各光路怎样平衡。 |
| `review_targets` | 最影响本轮成图的两三项可见关系。 |

在方向记录中完成选择，再编译具体方案。比如 [折面金属样例](../assets/image-direction.example.json) 使用一块条形扩散面塑造亮脊，深色反射卡定义相邻暗面，柔和接触影说明落地。它的抛光亮脊、拉丝凹面与纸张分别得到适合自己的光响应。

## 看图后的调节顺序

1. 先调整关键反射的方位、光面形状、宽度与明暗分区，让亮带服务曲率及信息阅读。
2. 再调整有效角尺寸、擦光方位和填影份额，使投影、细纹与来源工艺一致。
3. 光型成立后平衡输出与曝光，检查透射色密度、关键亮部和暗部。改变光路后重新评估曝光。

每轮只处理最影响结果的一项，沿用原有看图修正流程。实际测试、参考观察与创作设定分别记录。

## 真实拍摄时展开

器材选型、光量预算与现场执行需要产品尺寸、灯距、附件、曝光和实测条件。光束角用于描述覆盖，光源角尺寸用于判断物体看到的光面；点源距离关系在相应几何假设下使用，近场大面光按光路或测量分布判断。照度、发光面亮度和最终像素分别记录。连续光与闪光的时间、同步与环境光条件沿用 [摄影设定](photography.md)。

本指南依据用户提供的《Siuyu_Universal_Material_Lighting_Handbook.md》材质入口、光型比较、效果配方、光学条件与调节顺序提炼，并对上列原始资料核查。数值配方属于场景试拍起点；普通图像生成采用已选定的可见光路与摄影模拟设定。现场测量表和设备参数在真实拍摄任务中按需展开。
