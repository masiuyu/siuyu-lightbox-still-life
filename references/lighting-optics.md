# 从表面目标设计光路

先说明关键部位要看见什么，再说明这个结果由哪种光学作用形成，以及有效光面和暗面放在哪里。材料、几何、相机与光共同决定外观。

## 先选择观看重点，再给光分工

一束光可以同时影响多个表面。为它确定主要任务，并检查它对其他部位的影响，会比只列出灯名更容易调整。任务可以是解释体积、定义镜面曲率、显示纹理、穿透薄层、分开轮廓或保留图面阅读区。

先判断本张最重要的是完整外形、表面差异、透明厚度还是一种明确气氛，再选支持它的光。复合表面按 [构造案例](material-construction-cases.md) 分配观察：清漆反射与下层图纹保留各自阅读区，半透薄壁分别安排外表面反射和另一侧的入光，方向性材料结合加工分区及机位选择有效光面。只有当其他必要部位仍不可读时才增加补充作用。灯数、灯位和明暗比服从实际场景。

一句可执行的光路说明包含表面、有效光面或暗面、相对方位、产生的结果和需要保留的邻近内容。例如：“右侧竖长扩散面映入钢壶外壁，形成沿曲面转折的连续亮带；旁边较暗环境形成窄暗带，使外壁与浅底分开，壶身商标区域仍可阅读。”

## 分别决定光的方向、尺度、强度与颜色

| 控制关系 | 在画面中主要看什么 | 同时需要的条件 |
|---|---|---|
| 光源相对主体和相机的方位 | 受光面、投影方向、映入表面的亮暗区域 | 物件摆向、接收面与遮挡 |
| 物件看到的有效发光面大小 | 阴影过渡和光面形状；镜面还受曲率与表面响应影响 | 光源尺寸、距离、扩散和材料 |
| 光量及空间分配 | 明暗层次、局部对比、实体与背景的亮度关系 | 曝光和填光分工 |
| 灯色、环境色与材料响应 | 色光落在哪些面，哪些反射或透射带色 | 材料本色、有效光谱与相机解释 |
| 白平衡与最终色调 | 中性区、肤色和识别色怎样保留，哪些区域承担气氛 | 当前颜色依据与允许变化范围 |

柔和的阴影可以处在不同光色下；明亮的画面也可以有清楚的光面边界。先选择需要的可见关系，再让这些条件相容。指定柔光时说清有效发光面与受光位置；指定色光时说清颜色作用范围和物件本色的保留方式。灯的色温和像素的最终冷暖分别写明。

支撑或扩散结构按承托、传播及遮挡存在，研究媒介按当前需要承载的信息存在。普通生成把光路写成最终可见的关系，真实拍摄或渲染再检查对应设置。[颜色校准的输入与适应流程](https://github.com/darktable-org/dtdocs/blob/f9caae460253da24c948dd69c0d95835174c616b/content/module-reference/processing-modules/color-calibration.md) 可用于理解灯色、相机解释与输出颜色之间的分工。

## 给不同表面合适的光

抛光金属用亮面和邻接暗面解释曲率，亮带随局部曲面转折；拉丝面保留实际纹向与相应高光方向。清漆、釉层和亮膜同时保留表层反光与下方信息的阅读区。

透明材料用背景透射建立内部密度，亮暗反射定义边缘与壁厚；磨砂、纸层等散射体用底光表达厚薄，用克制表面光显示边界。哑光本色采用合适面光，压纹或织纹按其方向采用表面掠射和必要填影。

光滑表面可以映出边界清楚的大光面，投影的柔软程度另由光源角尺寸、距离和承影面决定。纸的散射、表面反射、接触影和镜头离焦各写其作用。[介质界面](https://pbr-book.org/4ed/Reflection_Models/Dielectric_BSDF) · [粗糙表面](https://pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory)

### 分开看反射与投影

镜面亮带的形状取决于物件向相机反射了哪片环境，表面粗糙度还会改变其过渡。投影则与光能否绕过物体到达承影面有关，接触距离也影响阴影形状。因此宽亮带可以有清楚边界，柔软投影也可以与光滑材料同时存在。

需要修正镜面亮斑时，先考虑物体、相机和有效光面的相对方向；需要改变投影软硬时，再检查发光面从该物体处看有多大及承影关系。[面光源示例](https://pbr-book.org/4ed/Light_Sources/Area_Lights) 展示了改变光源尺寸对明暗和投影的共同影响。

## 写成具体几何关系

说明物体实际看见的亮面形状、相对大小、长短方向与方位，哪块暗面定义曲率，以及这些关系在哪个部位形成什么边界。白卡和黑卡按本轮作用安排。尺寸未知时用相对覆盖和反射范围，有可靠尺寸时再写距离。

例如：“左侧条形扩散面沿长弧映出连续亮脊，相邻暗反射定义折面；下方乳白台面穿过描图纸，上方克制补光只让金属边缘可读。”让光面、材料与曝光目标共同支持这幅画面。

白卡可以给物件提供可反射或反弹的亮面；黑卡可以限制某个方向的环境光或形成暗反射。安排时说清它们改变哪块表面。卡片本身是否进入画面由本轮构图决定，普通成图只需描述物件上最终可见的关系。

扩大布局或移动光面后，从每个关键表面重新判断光的相对方位、可见角尺寸和覆盖。靠近某件物体的大扩散面，对远处物件可能覆盖较小，照度分布及反射形状也会改变；仅提高功率主要改变光量，具体软硬仍由几何关系判断。需要比较两种表面时，让它们各有可用的观察区，并说明比较条件。

观察现有窗光、台面反弹和环境暗面，再选择需要补充的作用。强硬投影可以表现构图和形体，柔和光可以支持细腻表面，按本张任务选择；在亮底上给白色模型保留侧面渐变与边界，在深色模型上保留必要折面和连接。光的效果由物件上的具体位置验收。[自然光与空间](https://github.com/Wang-Cankun/cankun-skills/blob/main/skills/art-photo-quiet-light/references/visual-language.md) 提供从已有环境安排光的启发，具体气氛及光源选择服从当前任务。

## 不同题材怎样选择光路

| 本张观看任务 | 可以采用的具体安排 | 同时检查什么 |
|---|---|---|
| 金属器物的曲率与抛光 | 沿长弧设置条形亮面，相邻暗面随曲面收放；连接处保留克制填光 | 亮带是否随形，开口和连接是否仍可辨 |
| 白瓷或浅色器物的体积 | 偏侧大扩散面形成连续明暗渐变，与浅底之间保留适度边界差 | 体积是否可读，阴影是否与支撑相容 |
| 透明玻璃的厚边 | 让背景透过主体，侧边安排可映入的窄亮面或暗面 | 厚薄、转角、开口和背景透射是否共同成立 |
| 木纹、压纹与织纹 | 让斜向表面光显出相关方向的微小起伏，用填光保留暗部阅读 | 纹理是否被夸大，整体是否仍保有原来的柔软或平整 |
| 描图纸交叠 | 底光穿过台面和纸层，表面补光维持纸边；同一线稿跨边界变淡 | 单层与叠层密度、纸边及下层线条接续 |
| 亮膜或釉层下的图案 | 把主要镜面反射安排在允许区域，留出足够阅读区 | 图案完整性、表层光泽与图面是否兼容 |
| 强烈气氛主视觉 | 选择方向明确的亮暗、必要的局部色光和有限清晰区域 | 主体身份、关键材料色与必要连接是否仍被保留 |

上表是选择依据，具体灯位由摆向和拍摄角度决定。半透明纸与不透明布同场时，分别安排透射和反射，使它们共同处在可信光场中。

## 光影也参与构图

相似的暗底可以承担不同观看任务。抛光金属靠映入曲面的亮暗形状读形，透明杯靠壁厚、反射与背景透射显出边缘，哑光果实靠受光面到背光面的渐变显示体积，剪影则由主体与后方亮区的边界成立。先选材料机制，再分配暗面和亮区；每张按其需要保留细节。

投影可以与实体形成大小、方向或负形的呼应；镜面亮带可以引导视线沿曲面移动；透射色可以把薄区与厚区分开。这些关系先服从物件、光向和承影面，再参与画面的明暗组织。

选择一项光影关系承担主要视觉作用，同时保留必要识别。长投影很抢眼时，让它与主体的面积和间隙共同平衡；强反光覆盖必要图案时，改变有效亮面的位置。物体移动、光移动和相机移动引起的变化分别写清，见 [机位与运动](camera-and-motion.md)。

## 发光物与环境各自承担什么

灯罩内部、屏幕或发光台面先确定真正发光的区域、朝向和遮挡，再安排受光邻面。金属外壳可以反射其他光面，邻近桌面可以承接光池；外壳读形、发光面结构和光池分别检查。普通底光研究继续保持台面向上透过纸层的关系。

在渲染中，相机中可见的背景与为物件提供照明、反射的环境可能分别设置。换成浅背景后，原先暗反射可能仍然存在；判断依据是实际光场。摄影或普通生成则描述当前背景、反射和受光是否共同可信，具体实现按工具能力核对。[环境光与背景分工](https://github.com/CloudAI-X/threejs-skills/blob/main/skills/threejs-lighting/SKILL.md)

发光核心、外壳及暗部难以同时读取时，把照明分配与 [成像处理](image-development.md) 一起判断。光晕、曝光和光源对邻面产生的照明分别承担作用，按本张阅读重点选择。

## 在同一场景中解决相互影响

光台底面过亮可能使透明主体和纸层差异变弱；大面积上方补光可能覆盖纸下线稿的反差；强烈彩色反射也可能改变产品识别色。先定位哪个作用正在冲突，再调整光的方向、覆盖、亮暗分区或相应表面的观看位置。

例如，同场拍玻璃瓶与压纹纸，瓶侧的亮面负责厚壁，斜向光负责压纹。让斜向光的主要作用落在纸上，同时检查瓶身是否多出遮挡内部的亮斑。真实拍摄与渲染可按条件用遮光或分区照明；普通生成写出这组可见结果，实际看图确认。

当全貌和细纹需要不同观察条件时，分配到主图与独立材料近景。两张图各自说明光路和任务，细节图提供其本身的观察；同一全图的细节仍从该图原生裁区核对。

## 颜色与偏振按观看目标选择

先区分色光照亮的区域、有色背景映入的反射、材料的透射色与图面本身的渐变。同一蓝色可以来自不同位置，改动时沿相应路径判断邻面变化。雾面界面的散射、后方主体离焦和前表面水滴分别指定清晰度。透明液面造成的折射变形、泡沫边界与承接面上的聚光纹样各有作用，具体见 [材料形成](material-process-atlas.md)。

分别说明物体本色、透射色、环境反射和白平衡。色温描述白光冷暖，实际颜色校准还依赖灯、材料与相机。真实光谱与测量使用对应记录。[光谱与颜色](https://www.oscars.org/science-technology/projects/spectral-similarity-index-ssi)

偏振按目标区域的颜色与光泽选择，保留需要的材质线索。交叉偏振涉及光源端和镜头端配合，实际效果与光损通过拍摄比较；生成图按可见反射变化验收。[偏振条件](https://www.edmundoptics.com/knowledge-center/application-notes/illumination/successful-light-polarization-techniques/)

## 调节与检查

先调反射方位、亮面形状和明暗分区，再调纹理光方向、投影与填影，最后平衡曝光。改变光路后重新查看必要颜色、高光和暗部。每次修正针对最影响结果的一项关系。

| 症状 | 优先观察 | 可能的下一动作 |
|---|---|---|
| 金属显得平淡 | 曲面反射是否几乎只有同一亮度 | 安排相邻亮暗反射，让形体转折可读 |
| 图案被白亮斑盖住 | 亮斑与阅读区的位置关系 | 调整有效亮面或物件摆向，保留图案与光泽 |
| 纸的交叠像同一种灰色 | 单层、叠层及笔迹的反差 | 平衡底光和表面光，明确散射密度与覆盖关系 |
| 接触像悬浮 | 支撑点、接触距离和阴影是否相容 | 回查实际支撑与薄厚，再安排相应接触影 |
| 织物看起来像硬板 | 大褶皱、细纹阴影和轮廓是否一致 | 保留柔软形体，减弱过强显纹并核对交织尺度 |

诊断光可以帮助区分表面问题，最终主图的光还要支持整体主次与气氛。新的照明在技术上清楚，也可能削弱原来的视觉主张，复查时两者都要看。

真实拍摄再展开器材、灯距、光量预算、闪光时间与测量条件。光束覆盖、物体看到的光源角尺寸、照度、发光面亮度和最终像素各自说明。普通生成把已选定的可见关系写进方向。[摄影执行](photography.md) 负责把它与取景、动作和清晰范围一起核对。

## 参数与方法的适用范围

光比需说明比较的是分别测得的光源贡献，还是画面受光面与背光面的结果；灯的输出、距离和遮挡也要与该定义相容。色温说明白光冷暖，产品颜色还受光谱、材料和白平衡影响。当前图像工具没有相应控制字段时，数字属于成像意图，其效果按图片判断。

社区 [产品布光方法](https://github.com/jokull/jokull-skills/blob/main/skills/blender-product-render/SKILL.md) 启发按作用命名与逐次看图。本指南将它用于不同材质和构图；具体灯位、数量、功率和渲染设置在当前场景中选择。
