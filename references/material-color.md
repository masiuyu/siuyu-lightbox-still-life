# 从物件材质到创意与配色

这份判断放在原有方向记录中：参考观察包含主体表面证据，搭配理由包含物件与色彩关系，摄影设定负责实现相应光泽。覆盖主体、模型、纸层、图稿、承托与每类道具，再细分外观确有差异、会影响拍法的部位。按 [全场景实物真实性](physical-realism.md) 同时考虑材料怎样形成边缘、厚度、形变和连接。

## 材料身份、表面工艺与照片外观

将用户提供的材料或工艺说明作为规格依据；从照片观察颜色、反射、透射和纹理，并写清判断范围。银色、金色等可见外观与具体合金、镀层、纯度分别确认。图像分辨率、现有布光和后期会影响表面判断；资料有限时，保持看得见的外观并记录尚待确认的材料信息。

先按 [场景载体](scene-context.md) 确认本轮呈现方式。原物的材料与工艺沿用来源，包括用户以原物身份提供的既有模型或手办。新建模型按 [模型建构](model-construction.md) 联合选择识别特征、成品尺寸、造型、材料与配色；植绒、彩绘、透明材料或其他工艺都可成为主体的表达。新建模型部位使用 `basis: designed`，在 `observation` 中说明来源依据，用 `appearance` 写当前形体、成型、涂装或材料分区，用 `light_response` 写对应光响应。

每个重要部位用一条记录回答：**哪里 → 证据来自哪里 → 材料与表面判断 → 要保留怎样的光响应**。例如，同一件饰品的外弧、内缘、中央片和连接件，可以按实际光泽差异分组。随新证据更新判断。

对本轮设计的物件，`appearance` 写出可制作的构造与表面：厚薄、边缘处理、细节层级、纹理尺度及必要接合；`light_response` 描述这些表面在共同光场中的表现。辅助物件保持自己的材料差异，图稿的绘制材料与其纸面分别说明。纸张层数、透明度、内容所在层与接触位置相互对应。

重点观察能区分表面的线索：

| 观察 | 可能影响的拍摄决定 |
|---|---|
| 反射带的形状、宽度、边界与亮暗过渡 | 调整光源的可见形状、尺寸和位置，保留可辨的表面曲率。 |
| 纹理的方向、疏密、尺度与连续性 | 让拉丝方向、细微云纹或颗粒只出现在证据支持的区域，并保持其相对物体的尺度。 |
| 平面、内缘、倒角与连接件的反射差异 | 对不同部位描述各自的光泽，保留边缘厚度和转折。 |
| 清漆或釉层、底材与局部磨损的叠加 | 分开表现表层反光与下方颜色、纹理和磨损。 |
| 透明度、透射密度与厚度变化 | 调整底光、侧光与反射补光，使边缘和重叠处保持合理层次。 |

照片中的反射同时受表面、几何、光源和观察角度影响。将多个可见线索一起使用；真实物理参数需有相应测量或规格依据。图像生成主要使用可观察的描述。[表面粗糙度与反射模型](https://google.github.io/filament/Filament.md.html)

## 光泽还原的执行方法

光滑反射面通过周围明暗面形成可读的反射；细拉丝表面要保留方向性；较粗糙表面仍需有符合材料的高光分布。大光源也能在光滑表面形成宽反射带，判断时结合带的边界、对比和位置。

先确定产品需要呈现的亮带、暗部和过渡，再设计柔光面、反光面及遮光。透光场景中，底光负责透射区域，反射照明负责不透光主体的表面识别。色面进入反射的范围也属于布光设计。[反射与透射照明](https://broncolor.swiss/news/how-to-shoot-with-reflection-elements)

按 [材质目标与光路](lighting-optics.md) 将这些外观目标落实到有效光面、局部曲率、反射方向及明暗面分工。复合产品分别照顾表层反射、底层信息和透射密度，并为关键文字保留阅读区。偏振按本轮颜色与光泽目标选择。

原物复查时把原图与成图中的同一部位放到相近物体尺度观察，比较光泽类型、亮带边界、过渡、纹理方向与表面色。重新布光可以改变反射位置；保持材料身份、表面工艺和局部差异是主要目标。模型先核对来源识别特征及其体块、连接和细节是否与所选工艺相容，再核对材料表面与光泽。

## 从主体推导创意

先提取这件物品的一个具体特征，再将它转译为材料、空间或观看动作：

- 开口、环绕、折返、重复：由负形、叠层、连续边缘或间距来呼应。
- 冷暖两种表面、光滑与粗糙、透明与实体：由有依据的材料对照建立主张。
- 可确认的制造、使用或运动关系：由部件、痕迹或动作组织画面。

说明创意与主体的联系即可。构图清晰且主体自身已有足够色彩关系时，可让中性环境和光泽承担主要表达。需要更鲜明的视觉主张时，再赋予色场、辅助材料或道具一个明确作用。

结构与解构表达按 [从主体发展结构](subject-structure.md) 选择。模型本身可以通过概括体块、材料转换与配色形成主张，再由辅助图稿和样片展开相关轮廓、节奏或纹样。围绕同一主体比较材料方案时，分别说明每种表达怎样保持用户所需辨识。

## 配色的四个决定

1. **依据**：原物采用来源色彩依据；新建模型说明所选涂装、单色、材料本色或透明色怎样服务识别与主张。用户明确指定的色区继续保留，当前参考的作用具体说明。
2. **关系**：选择同色相层次、邻近色、冷暖对照、互补倾向或中性色衬托。把色相关系与明度、饱和度一起考虑；配色名称只是组织方法，效果通过具体画面判断。[色相与配色关系](https://www.adobe.com/express/learn/blog/color-wheel-explained)
3. **分配**：明确产品色、环境主色、支撑色与必要强调色分别出现在哪里、占多大视觉重量。产品自己的颜色也可以承担强调色。面积、明暗、饱和度和接触边缘共同形成层级。
4. **反射控制**：区分物体自身的颜色、环境反射和整体白平衡。决定色面与金属的接触范围、角度和反射作用，让关键表面保留可识别的材质线索。

没有指定色彩方向时，简短比较有实质差异的方案，并按主体识别、光泽表现、构图和表达目的选择一条执行。已有明确方向时直接细化。颜色取样和色值用于定位候选；精确产品色需要经校准的来源。

举例：同一件冷色外壳、暖色连接件的产品，可以用中性灰让自身冷暖成为焦点，也可以用低饱和冷色支撑暖色细节，或让相近暖色通过明度差形成层次。选择取决于本轮画面主张与实际表面反射。

## 写入实际提示词

`design.materials` 可使用部位记录列表：`sources` 指向实际输入；`part` 标明部位；`basis` 取 `observed`、`provided` 或 `designed`；`observation` 写观察证据；`appearance` 写材料、表面和判断范围；`light_response` 写要保留的光泽与纹理特征。`observed` 需要图片来源和可见证据。

`design.palette` 使用 `basis`、`relationship`、`application`、`reflection_control` 四句记录。编译器将材质证据放在创意之前，将配色理由、应用与反射控制写入同一条实际提示词。简短描述也可编译；材质保真或配色判断是本轮重点时，使用上述记录。

字段完整性说明信息被传递；判断是否准确与画面是否好看，通过原图、成图和用户反馈确认。
