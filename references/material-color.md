# 材料与颜色怎样支持画面

先判断材料的哪一种变化承担本张的观看任务，再把它与形状、光和取景共同设计。主体、纸层、承托与道具都采用相容判断，明显不同的表面分别描述。本指南适合材料新设计、表面保真、局部修正与跨题材创作。

需要选择材料构造、加工或状态时，先读 [材料形成](material-process-atlas.md)：织线如何成为图形，木纹怎样随部件转向，蜡怎样保留压印，凝结层怎样改变遮显，各自会改变形体、边缘与光的任务。复合材料再按 [构造案例](material-construction-cases.md) 选择叠层、并置、颗粒混合、厚体包裹或薄壁散射，并安排可读的观察。这里细化表面响应。图稿的材质与成品材质可以不同，二者通过本轮研究问题建立对应，具体见 [研究媒介](study-artifacts.md)。

## 分清观察、规格和设计

用户材料说明提供规格，照片提供可见颜色、反射、透射与纹理，本轮新建物件提供设计选择。金属外观与实际合金、镀层或成分各有自己的依据；布光和后期会改变照片中的表面线索。资料有限时保留可见外观，具体未确认信息写在工作记录。

每个重要部位用完整一句话说明：哪里，依据什么，要保留怎样的表面，它在所选光下怎样可见。模型同时说明材料如何形成边缘、厚度、体积与连接；图稿的绘制材料和纸面各有做法。

## 分开描述，再检查共同结果

把下面几项作为思考工具，按任务选用；成像说明写成相互支持的完整句子。

| 需要判断的关系 | 主要描述什么 | 图中怎样检查 |
|---|---|---|
| 颜色与覆盖 | 本轮颜色落在哪层、哪片区域，底下内容透出多少 | 比较覆盖边界、同一层的延续和必要识别色 |
| 反射响应 | 反光边界清楚还是柔和，周围明暗怎样映入表面，纹向怎样影响反光 | 在适当亮暗交界查看反射形状与过渡 |
| 局部起伏 | 细纹、压纹、刻槽、颗粒和纱线的方向、密度及深浅 | 查看纹理边缘、微小阴影与跨区域连续性 |
| 体块与厚度 | 外轮廓、开口、折面、涂层边缘与实际连接 | 检查轮廓、内缘、遮挡和接触 |
| 透射与内部 | 光经过的材料厚薄、散射、吸收与可见内部 | 比较单层与叠层、厚边与薄区、被覆盖内容 |

这些关系有共同物理原因，分别描述有助于定位修改对象。复合表面还要决定每项属于哪一层，以及表层怎样随下层起伏：平整清漆可以覆盖有色图纹，薄覆盖也可以顺着底材组织延续，各层按当前构造处理。最终外观仍由材料、几何、照明、相机和成像处理共同形成。照片中的深浅不是一张可直接提取的固有色图；孤立的亮斑也不足以确定粗糙度。

例如，一块有深色木纹的涂漆木板，可以同时具有平整外形、木纹色差和连续的清漆反射。只有当设计或来源显示木纹确有沟槽时，才给相应部位安排起伏。把“纹理明显”落实到颜色、反光或凹凸，能保留这几种不同结果。

## 薄层、体积与纤维分别解释透光和反光

先选择当前可见作用来自薄表面、具有厚度的透明体，还是纤维覆盖层。薄玻璃和透明膜可以同时具有背景透射与表面反射；有色树脂或玻璃体的厚薄、光在内部经过的距离与吸收共同影响密度。把厚边、薄区和内部阅读位置一起安排，比单独指定透明程度更有判断依据。

需要区分表面染色与体积吸收时，让两处不同厚度共享可比较的照明。表面色层沿覆盖范围分布，体积色密度按光程与形状形成变化；磨砂界面还会使透过的内容柔化。实际渲染采用当前引擎支持的薄壁、体积及散射模型，参数解释按该模型核对。[透射规范](https://github.com/KhronosGroup/glTF/blob/7cee0fcddd5730e90d488bfb5aa2e52171483dde/extensions/2.0/Khronos/KHR_materials_transmission/README.md) 与 [体积规范](https://github.com/KhronosGroup/glTF/blob/7cee0fcddd5730e90d488bfb5aa2e52171483dde/extensions/2.0/Khronos/KHR_materials_volume/README.md) 提供这一分工的原理；体积规范中的吸收与折射说明按其限定范围使用。

绒面织物的表层纤维可以在掠视方向形成柔亮边缘，同时基底保持漫反射和较暗色块。先安排大褶皱、受压形变与纤维方向，再选择该观看距离能辨认的绒毛。表层纤维反光与底材粗糙程度分别判断，材料身份由轮廓、触地、褶皱和光响应共同支持。[织物 sheen 模型](https://github.com/KhronosGroup/glTF/blob/7cee0fcddd5730e90d488bfb5aa2e52171483dde/extensions/2.0/Khronos/KHR_materials_sheen/README.md) 提供纤维反射与底层分工的参考。

这些原理用于选择可见目标。图像提示词写厚薄、边缘、密度、透过内容和纤维反光，真实材质测量及渲染器数值采用对应证据。

## 决定纹理在什么尺度出现

先按 [视觉层级](visual-hierarchy-smooth-control.md#给纹理具体位置和作用) 选择本张依赖的材料线索，再决定在哪片表面、以多大面积和什么清晰范围显示。整体产品图由体量、反射、色差或连接建立材料身份，微距研究再把指定结构作为主要尺度。不同材料保持自己的响应，光滑区域与天然纹理各按实际构造成立。

先看整体轮廓和体块，再看中等尺度的纹理组织，最后看接近原生像素的表面细节。木板的排列、沿长轴弯曲的木纹和微小毛孔各占不同面积；织物的褶皱、经纬交织和单根纤维也分别处理。

微小起伏在远处可以主要表现为反射的柔化，未必能逐粒辨认。细缎面可让宏观曲面保持连续，反射边界较抛光参照柔和；拉丝还需说明沿局部曲面的纹向。刻槽则需要明确的路径、深浅与边缘。有关微表面与方向性的原理见 [粗糙表面](https://pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory)。

给关键细节足够原生面积，具体安排见 [取景与细节](camera-framing.md)。当取景不足以读取纤维或细纹时，采用该尺度仍可见的材料线索，把微观检查留给合适的近景。为了在全图中显出每条细纹而扩大其沟槽，会改变原来的表面意图。

## 纹理属于物体的局部表面

先说明纹理沿哪片表面、以什么方向延续。圆柱的环向拉丝绕圆周连续，轴向拉丝沿圆柱长轴；弯折带材上的纹路随当前表面转折。相机转动后，它们在画面中的方向可以改变，仍属于同一块材料。

木纹按木件及拼接关系延续，布的经纬随布面弯曲，印刷图形按自己的内容附着其上。材料拼缝、换件或明确加工分区处可以改变纹向，平滑连续的表面采用相容接续。不要让一种跨全图的条纹替代各物件自己的纹理。

同时区分局部纹路方向、反射的方向性和图像采样。拉丝可能使反射呈方向差异，具体亮带仍受曲率、光与机位影响，不能只凭亮带朝向确定加工纹向。渲染中的纹理过滤也有各向异性设置，它解决斜视纹理采样，与材料反射方向性各有作用。[材质方向性](https://threejs.org/docs/pages/MeshPhysicalMaterial.html) · [纹理变换与过滤](https://github.com/CloudAI-X/threejs-skills/blob/main/skills/threejs-textures/SKILL.md)

若图中细纹过强，先看它是否真是表面起伏，再比较光向、观看面积和锐化。成像处理的具体诊断见 [从光场到最终图片](image-development.md)。

## 同一处变化由相容的材料原因解释

先说明一处痕迹怎样形成，再决定它是否同时改变颜色、反光、起伏或覆盖。金属划痕可能在细槽及相邻表面形成不同反射；磨穿的涂层会在同一位置显出底材；木纹色差可以位于平整清漆下。各项可以分别调节，位置、尺度与层次共同服务这件表面。只有颜色变化的平面印色按其实际媒介呈现。

连续表面上的加工纹、覆盖边缘和使用痕迹沿物件延续；局部编辑后检查相邻部位和用于比较的材料样片。样片若研究同一种成品表面，其纹理尺度与光响应应能对应；若展示不同加工阶段，明确各自身份。

细节随观看距离改变表达。远处难以分辨的细纹仍可能共同影响反射过渡和表面整体观感，近处才逐渐显出单条结构。保留材料的物理或设计尺度，再检查整体、中景与必要近景；避免用逐条强化的沟槽承担全部材质识别。真正渲染时按像素覆盖选择过滤及法线处理，普通生成则说明远近各能看见什么，实际输出核对。

[程序材质](https://github.com/linegel/threejs-complete-set-of-skill/blob/main/skills/threejs-procedural-materials/SKILL.md) 启发共享成因、位置与尺度的判断；[纹理采样](https://pbr-book.org/4ed/Textures_and_Materials/Texture_Sampling_and_Antialiasing) 解释表面细节到像素的映射。节点、混合公式和过滤实现按实际渲染器另行验证，材质成因直接写成自然语言即可。

## 按层解释复合材料

先确定底材的连续形状，再说明上层覆盖的范围、厚薄和自身光响应。底材颜色是否可见，与底材起伏是否还能辨认，是两件需要分别决定的事。

薄而不透明的墨可以覆盖布色，同时随较大的纱线起伏延续；较厚覆盖可能填平纤维间隙，使细纹减弱。实际能保留到哪个尺度，由本轮工艺意图和成图共同判断。透明清漆则可以保留下层颜色与图案，在表面增加自己的反射。纸层采用相应透射与散射关系。

对层序有疑问时，选择层与层相遇的位置观察：涂层收边、露底区、墨线端点或纸层交界。写清楚上下关系与连续范围，再用实际图确认；独立材料小样的具体路径见 [印刷判断](print-direction.md)。

## 让不同题材各有明确的材料行为

下表是设计例子，采用哪项关系由当前物件和观看任务决定。

| 题材与目标 | 可以直接写入方向的描述 | 必须继续保留的关系 |
|---|---|---|
| 金属器物，比较抛光与细缎面 | 两处表面保持同样的圆润曲率；抛光区映出清楚条形亮带，细缎面区的反射过渡更柔和，近看才出现细密纹理 | 轮廓、厚度、连接、金属颜色与可比较光面 |
| 釉陶器皿，区别釉面与陶胎 | 有色釉面上有连续柔亮反射，外缘露出的陶胎呈细密哑光；二者的边界沿同一器形接续 | 本轮设计的施釉范围及边缘体积 |
| 透明玻璃，读出厚壁 | 周围背景透过瓶身，厚边与转角改变透射密度和背景的可见形状，侧边留出相邻亮暗反射 | 容器结构、开口与玻璃的透明范围 |
| 木材，保留木纹与清漆 | 木纹色差沿板长弯曲，平整清漆表面映出连续光面，已有压痕只在原部位形成起伏 | 木纹方向、板面平整程度和已有损伤 |
| 织物，解释柔软与覆盖 | 大褶皱决定受光面，经纬节奏沿表面延续，薄墨随交织起伏覆盖并形成独立收边 | 布的交织组织、支撑和墨层范围 |
| 纸张，区别平面印色与压纹 | 印色在平面上连续；局部压纹在斜向光下显出细小成对明暗，纸边保持相应厚度 | 图面内容、压纹位置与薄纸身份 |

需要风格化表现时，说明哪些纹理被概括、哪些明暗被夸张，并保持主体识别与本轮媒介的一致性。写实检查按本轮明确选择的表现方式采用。

## 从表面安排光

结合亮带的形状、边界、过渡，纹理的方向与尺度，以及倒角、内缘、涂层和厚度判断表面。大光面可以在光滑物件上形成宽亮带，表面粗糙度需要多个线索共同说明。真实物理参数按规格或测量确认。[反射模型](https://google.github.io/filament/Filament.md.html)

抛光面用明暗反射解释曲率；拉丝面保留纹向与适当高光；透明材料用透射密度和边缘说明厚度；纸与织物通过本色、细纹和微小阴影表现表面。默认底光负责半透明层，克制补光负责实体识别。[光路判断](lighting-optics.md) 将目标转为具体光面与方向。

颜色在不同材料中的作用也不同。普通透明清漆的表层反射与下层色相分别判断，金属的有色反射则参与其材料身份；环境色、白平衡和曝光仍会改变照片中的表现。实际材料分量与参数按对应模型和资料确定。[材料与光的共同作用](https://google.github.io/filament/Filament.md.html)

## 配色用四句话讲清楚

先讲依据：哪些颜色来自原物，哪些来自用户指定或本轮材料设计。再讲关系：冷暖、明度、饱和度怎样组织主次。接着讲分配：颜色落在哪件物品上，占多大面积和视觉重量。最后讲反射：环境色怎样进入金属、透明层或表面，同时让主体材料仍可辨认。

已有明确方向时直接落实；开放设计可以简短比较有实质差别的方案。中性环境、同色系或有限撞色都按观看目标选择。屏幕 RGB 是颜色意图，精确产品色与物理油墨颜色需要对应校准。

需要把不同来源组织成系列时，先比较保留原色、局部色调映射和背景分离三种路径，选择能保存关键识别的做法。明暗进入两种颜色时，给脸部、开口和连接留下必要区分；每种颜色附着在指定图面或墨层。实物反射、场景灯光和印刷颜色各按自己的原因成立，具体案例见 [案例学习](case-derived-lessons.md)。

深色结构墨接近深色布时，选择它与较亮第一墨相遇的位置观察，明确第二墨是叠在第一墨上还是直接接触底布。先检查指定配色与光能否显出差别；改变既定墨色、分色位置或覆盖关系作为具体设计决定另行记录。需要保留原色的物件可以用底面、辅助色与反射关系形成系列。

## 看同一部位

把来源与成图中的同一部位放到相近物体尺度，比较光泽类型、纹理方向、厚度和材料差异。重新布光可以改变反射位置，材料身份和实际保真范围继续对照。新模型同时检查当前工艺怎样形成体块与表面。用具体关系写评审，字段齐全和漂亮描述分别保留其证据边界。

## 从症状选择下一次调整

| 实际所见 | 先区分的可能原因 | 本轮可选择的调整 |
|---|---|---|
| 细缎面出现粗大凹坑 | 纹理尺度、起伏幅度与照明显纹程度 | 保留曲面，只收细指定区域的纹理与起伏，再用同一参照观察 |
| 哑光看起来像表面脏斑 | 不均匀颜色、反射变化或不相容的阴影 | 明确本轮是否需要色斑；表面颜色平稳时用反射柔化表达光泽 |
| 一处宽白亮斑掩盖表面 | 光面形状、反射方位、曝光或材料响应 | 先让相应亮面移开关键细节，再判断表面是否需要改变 |
| 墨线像凹槽 | 底墨范围、层序、颜色与高度被混用 | 在端点附近建立连续底墨与上层收边，分别检查颜色覆盖和底材起伏 |
| 透明物件近乎实心白块 | 光台过亮、反射覆盖、内部结构或透射描述不足 | 先给边缘与背景透射可读范围，再核对容器厚度与曝光 |

每次选择一个最有证据的解释作为调整目标，保存其他已成立关系。新生成仍可能发生伴随变化，成图后要重新检查；只有一张图片时，原因可以保留为待验证判断。

## 方法依据与执行边界

社区 [材质模块方法](https://github.com/spurbro/stylized-substance-designer/blob/main/SKILL.md) 提供通道和层次分工的启发。本指南将它转为面向不同图片任务的自然语言判断，表中的摄影应用是当前设计方法。法线贴图与凹凸贴图对着色的作用可参照 [材质实现](https://pbr-book.org/4ed/Textures_and_Materials/Material_Interface_and_Implementations)；实际改变轮廓与遮挡还要处理相应几何。

文生图用可见关系描述，渲染任务再使用当前渲染器实际支持的参数。节点值、颜色意图、图片观察及真实材料测量分别保留各自依据。
