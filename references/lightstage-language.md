# 连续柔光中的材料与陈列

用于延续 Siuyu Lightbox 的系列语言、把新产品放入柔光场景，以及从材料静物参考发展构图。先读当前参考，确定这次共同保留的光场、轮廓、空间和材料关系，再选择机位与具体做法。用户明确指定独立摄影、绘画或其他风格时，按该任务展开；系列展示采用已经选定的共同关系。

## 让不同题材属于同一组图片

这套语言通过受控制的光场、清楚的实体轮廓或材料观察窗口、可读的材料和有目的的空间疏密组织画面。光场可以呈现乳白透射、奶油色背景、琥珀渐变或深浅过渡；宽亮面与邻接暗面共同解释体积。产品颜色、材料状态和构图可以变化，共同关系要落在图中具体位置。

开始时用几句自然语言写清：大面积背景怎样形成；主体靠什么亮暗边界被辨认；材料怎样回应光；什么形状关系组织空隙。写进成像说明，再把这些位置列入核心观察。背景明亮或配色相近，只能支持其中一部分判断。

完整陈列可以用宽阔空隙建立尺度，材料特写可以用大形压满画幅，并让局部亮暗与前后虚实组织观看。按本张任务选择舒展或紧凑的构图，必要识别与材料窗口各有清楚位置。产品镜头的具体联动见 [摄影关系](photography.md#产品镜头把材料位置与光一起确定)。

换主题时可以改变盘卷、折叠、垂坠、悬挂、靠置、并排比较、完整陈列或局部取景。形态变化需要材料和承托共同成立：纤维服从拉力与重力，薄片显示弯曲和边缘，硬质组件显示厚度与连接。支架、线绳、夹具和样片只在承担这次需要的关系时进入。

## 按观看问题选择舞台

| 这次需要看见什么 | 可采用的场景与机位 | 在原生图里检查什么 |
|---|---|---|
| 平面布局、纸层和薄片密度 | 连续乳白发光台，垂直俯拍；侧面补光按实体需要选择 | 发光面从间隙连续露出，薄层交叠改变密度，实体表面与接触仍可读 |
| 卷绕、垂坠、堆叠或立体形态 | 大面积明亮扩散背景，正视或斜视；宽柔光照顾实体正面 | 背景通过孔洞和空隙可见，实体保留体积，承托和遮挡明确 |
| 金属、织物与透明件同场 | 发光台或扩散背景建立大关系，宽亮面与有限暗反射解释硬质表面 | 金属曲率与厚边、织物折弯、透明厚边分别成立；同处共享可信光场 |
| 透明体与有色液体的层次 | 正面或斜视读取液位、厚底与侧壁，背景亮区和暗边按视角安排 | 玻璃表面反射、内部透射色、液面和背景各有可读区域 |
| 材料特写与前后层次 | 贴近选定界面，明确允许越出画幅与柔化的位置 | 关键厚边、接口或加工连续可辨，虚实过渡服从前后距离 |
| 重复形体与光学叠压 | 俯拍或轴向观察，依据实体高差组织重复、错位及重叠 | 相邻轮廓、接触和透射密度可读，亮带跟随实际曲面 |
| 少量图形承载故事或艺术风格 | 实物、模型与当前所需的图稿、印面、薄片或屏幕共同陈列 | 图像内容附着于指定载体，载体有厚度、边界、支撑和场景受光 |
| 一个完整的物件主视觉 | 根据识别面选侧视、斜视或俯拍，给轮廓和空隙足够面积 | 第一眼读到整体形状，细节集中在需要辨认材料或结构的位置 |

简短光台请求继续采用主入口中的底光俯拍。用户给出侧视陈列参考时，依据它选择新的观察位置和承托；俯拍和侧视各自维护相容的支撑与光路。

## 柔光源与发光舞台分别设计

画外柔光箱主要改变物件的受光和反射。相机可见的发光台或扩散背景则直接组织画面中的大面积亮区。按需要分别安排，并说明它们怎样共同作用。

金属在宽亮面与邻接暗反射之间显示曲率，孔口可以露出后方或下方光场。纤维在正面宽柔光下显示整体体量，稀疏边缘在逆光中显出少量透光；密实织带仍呈现自己的不透明表面。透明物件用厚边、反射和背景透射共同读形。具体关系沿 [光路](lighting-optics.md) 与 [材料](material-color.md) 展开。

明亮背景和实体正面的曝光共同平衡。正面太暗时调整有效补光及反射；边缘被亮底淹没时调整主体摆向、暗反射或背景与实体的亮度关系。空隙保持通透，实体暗部保有必要层次，接触由局部阴影、压痕或承托解释。

背景的明暗、色相和渐变范围以当前参考和用户选择为准；材料的自然暖色继续属于该材料。灯色、白平衡与输出色调分别判断。描述已有照片时只记录可见结果，实际灯型、数量和位置依据现场资料确认。

彩色主视觉分别确定背景色、实体或液体的透射色、表面反射与输出调色。蜂蜜色液体可以处在琥珀渐变前，玻璃的部分亮带仍保留近中性色，厚边和重叠区域按自身光程形成深浅。背景亮区的位置服务轮廓、液体和文字阅读，改变机位后沿 [光路](lighting-optics.md#透明材料的视角光场与层次) 重新检查。

道具先选择实际作用：用相容的轮廓呼应主体、形成可读的遮挡与纵深、改变透过的背景或映入表面的明暗、说明尺度或承托。每件道具的位置和材料要交代它怎样改变这张图；少量重复主体本身也可以组织图形。用户已锁定物件及布局时，在该范围内细化。

## 用形态建立变化

一束材料可以在卷绕与松散之间形成对比，一段织带可以用宽弧与硬质开口形成负形，一片透明材料可以用弯曲和厚薄改变背景。先找到当前主体自身能承担的动作，再选择陈列方式。辅助物与主体的联系需要看得见，例如承托重量、对照加工阶段，或解释连接。

留白由实体边界、穿孔、架间空隙和各组之间的距离共同形成。按当前画幅选择完整或局部取景，必要的受力点与识别面保留在观察范围内。摄影中的悬挂说明连接点和下垂方向；改变画面方向后重新检查重力与承托。

纹理按观看距离出现。整体先读到盘卷、垂坠、折面和反射，再在原生细节中辨认纤维或加工。材料保留真实的不均匀和微小起伏，背景与无信息区域保持安定。具体控制见 [视觉层级](visual-hierarchy-smooth-control.md)。

## 新媒介怎样接入系列

叙事可以通过物件状态、加工先后、模型动作、痕迹或图面内容表达。需要延续这套实体陈列语言时，先决定故事由哪种实物关系承担：原料与成品、正在完成的连接、手和工具的接触，或实物与研究影像的对应。

水彩、单色印刷、扫描及内部结构影像可以成为纸、布、薄片或屏幕中的内容，也可以由实体材料重构形状。载体依据本次目的选择，图面内部的投影和色彩与载体在场景中的受光分别描述。用户明确要求独立水彩或整幅情境摄影时，继续按照该产物执行，并以其自身标准评审。

系列展示选图同时检查任务目标与约定的视觉关系。主图、说明和图库用图片实际证明的范围介绍能力；可编译方向用于准备，成图与用户审阅分别记录。

## 实际图片的核心观察

| 检查位置 | 需要看见的关系 |
|---|---|
| 全图与缩略观看 | 主体轮廓或指定材料窗口先被看见，空间疏密、光色与选定系列相容 |

| 接触、悬挂及支架 | 重量、承托、受力和阴影共同成立 |
| 原生材料区域 | 纹理尺度支持材料身份，整体信息密度维持本张主次 |
| 新题材与既有参考并看 | 能在具体的光、轮廓或观察窗口、空间及材料位置指出共同关系 |
