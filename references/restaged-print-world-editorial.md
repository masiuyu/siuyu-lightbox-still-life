# 从观看目的选择成像方式

用于开放构图、换媒介、场景创作及系列适配。先确定当前图让观者获得什么，再选择能让它成立的可见关系。单项明确修改直接处理相关部分；用户已经选定的身份、布局、风格和材料继续作为依据。社区研究的具体启发见 [方法来源与贡献](method-sources.md)。

## 找出真正需要解决的观看问题

“呈现一只扣件”还不足以决定画面。需要看清它的轮廓、表面处理、织带穿行，还是使用者的动作，会导向不同方案。选择可以用成图判断的目标，例如“先看懂织带怎样折返，再读到金属与纤维的接触”。方向只写采用的结果；比较理由留在记录。

| 观者要获得什么 | 优先安排什么 | 会牵动哪些决定 |
|---|---|---|
| 辨认个体或产品 | 识别轮廓、部件和比例 | 摆向、遮挡、机位及允许裁切 |
| 分辨材料或表面 | 有代表性的受光面及交界 | 光面大小、入射方向、背景反射与原生细节面积 |
| 看懂结构或动作 | 连接、运动方向与关键时刻 | 摄影、示意或局部剖示，部件范围与阅读顺序 |
| 理解多人关系 | 谁影响谁、通过什么动作或物件联系 | 分组、间距、通路、纵深和焦点层级 |
| 进入一种情绪或观念 | 可见的空间、色调、节奏或事件 | 观看距离、环境改动、形式概括与信息密度 |

同一对象可以完成不同任务。表面比较采用能读到反射和接触的摄影；穿行说明可以采用线与局部遮挡；情境图把扣件放回手与衣物的关系。媒介由要传递的信息选择，具体材料继续按对象判断。

## 让各项决定互相提供条件

先保留本次必须成立的身份和关系，再找最影响目标的一项决定。它改变后，复查受影响的机位、光、材料和信息范围。下面的关系用于发现矛盾，普通任务按需要选用。

| 改变什么 | 需要同时考虑什么 | 值得观察的结果 |
|---|---|---|
| 机位与投影 | 遮挡、尺寸关系、动作方向、可见表面 | 接口能否看清，人物与物件是否仍属于同一空间 |
| 材料与构造 | 厚度、软硬、覆盖、方向性及承托 | 弯折、厚边、反射及接触怎样共同说明材料 |
| 光的方向或发光面 | 相机位置、表面曲率、邻物反射与曝光 | 有效亮暗分界是否落在需要阅读的位置 |
| 色彩与明暗 | 主体识别色、环境光、输出工艺及阅读距离 | 观者靠颜色、明度还是轮廓区分信息 |
| 密度与分组 | 局部事件、空间路径、尺度及最终显示面积 | 远看能否分组，近看能否找到动作的联系 |
| 文字或图形 | 实际阅读任务、媒介、边界与主体占比 | 文字是否帮助理解，图形是否有明确内容归属 |

例如，想让喷砂金属和织带的区别可见，可以把扣件略转向一块长形柔光，让金属保持宽而连贯的反射，织带在孔口处弯折；机位同时看见孔边与折返。若变成装配说明，就用一致的视向和遮挡关系解释穿行，微观反射让位于结构阅读。

## 给空间和人物选择合适的关系

新场景先确定人物正在完成什么，以及身体、物件与环境怎样支持它。摄影中的动作需要站位、承托、目光和接触共同成立；绘画可以选择透视、轴测、地图式安排或其他指定投影，各物件沿选定规则进入空间。人物多少、大小、细化程度和色彩分组由活动及观看距离决定。

群像先分配互有关联的活动：搬来育苗盘的人把它交给台边的人，整理苗床的人为下一盘留下位置。动作之间的交接可以组织视线；建筑开口、工作台和走道提供尺度。若活动本身已有明确中心，环境围绕它组织；若是分布式日常，利用多个可以逐渐发现的联系维持整体阅读。

当用户要求陌生或不可能的环境时，从当前主题选择空间、尺度、反射、时间或图像层之间的变化。明确哪些关系采用摄影条件，哪些属于本轮设计。环境的改变需要使主题更可见，身体与物件沿当前设定保持相容。用户明确保留的构图和局部范围继续优先。

故事由可见关系发展。雨夜门口递出一件干外套，接衣者仍扶着一辆车，修理中的车轮留在灯下，动作便包含了前因与后续。观看位置决定观者能读到多少，光和材料帮助区分室内外及人物距离。具体时代、风格及必要文字依据当前题材选择。

## 决定照片、图形和印色各负责什么

先确定资料在当前任务中的用途：忠实呈现、结构说明、关系比较，或开放转译。摄影擅长材料与接触；线描、剖示和动作序列帮助阅读结构；色块、路径和简化标记可以突出关系。选择有信息贡献的部分，必要时在一幅图中协调这些表达。

例如，要解释织带折返，可以采用一个清楚的装配视图；要比较表面，就给两种材料足够的原生面积；要建立主题联想，再选择与内容有关的形、文字或相邻图像。照片的保留范围按当前要求落实，精确嵌入与映射沿 [本地工作流](offline-workflow.md) 执行；生成式重建按实际结果检查身份与内容。

印色数量由输出任务决定。一墨任务用覆盖、网点和露出的基材组织明暗；多墨任务说明每版承担的内容与交叠；彩色摄影中的颜色同时受材料和光影响。具体层序及工艺见 [印刷判断](print-direction.md)。配色、纸面、画幅和文字关系跟随本次内容发展。

## 用新任务检验方法能否迁移

迁移时先确定新任务的差异会改变什么。透明体、纤维、群体活动和结构图对光、机位及密度有不同要求；据此重新求解。用户要求延续系列时，保留已经选择的共同关系，再让新对象的材料与动作形成自己的实现。

当前随包 [摄影方向](../examples/task-led/buckle-photo.md) 与 [装配方向](../examples/task-led/buckle-diagram.md) 使用同一扣件主题，分别服务材料和结构；[雨夜动作](../examples/task-led/rainy-doorway.md) 与 [温室群像](../examples/task-led/greenhouse-groups.md) 分别选择单项交接和多人工作联系。方向可以编译；材料摄影、雨夜场景与水彩群像的当前样张见 [图库](example-gallery.zh-CN.md)。两个扣件方向的设计一致性及结构说明继续按实际图像验证。

## 执行与回看

按当前接口写参考图片和成像说明，提示词依次落实主体层级、构图、关键光色材质和必要细节。[Smooth Control](visual-hierarchy-smooth-control.md) 依据当前摄影、绘画或印刷方式组织大尺度关系，必要纹理由材料及观看距离决定。

成图先问观看目标是否实现，再定位问题：接口被遮挡时回到机位，材料混淆时检查构造与受光，人物联系不清时检查动作和距离，图形信息过多时检查阅读任务。全图及目标显示尺寸检查组织，原生区域检查本图实际包含的必要细节。技术检查、真实画面与用户接受分别记录。
