# 织物与纸面印刷概念

## 参考图片

本例采用纯文字概念，创作一幅有限蕨叶轮廓研究。

## 成像说明

生成一张完整 9:16 的垂直俯拍静物。细密交织的深蓝书布平铺并延伸到四边四角，表面受上方左侧大柔光照明。单幅蕨叶图形印在中央布面：暖白专色组成完整叶片和叶柄，深蓝灰第二专色表达少量叶脉。主体轮廓周围有连续露出的布面，暖白大色块覆盖充分。

两种墨直接附着在同一布面，其边缘、微小厚度和光响应随原有纤维起伏变化。在叶片外缘选择几根可以从露出区追踪到印区的纤维，使交织位置与高低连续；覆盖差只在局部低处克制变化。第二种墨在颜色与沉积边界上独立可辨，原生观察能比较底布、暖白墨和深色墨相邻的位置。

下方放一张完整小矩形未涂布纸，印同一蕨叶的四色调子研究。纸面采用细胶印点形，先保留轮廓和调子，本张以轮廓和调子可读为先，细点与纸齿按实际原生面积观察。纸与图像作为一个平面轻微旋转，有薄边和落地接触。布面专色、纸面四色和各自光响应分开成立。所有轮廓与纸角完整，主次清楚，关键印区有足够画面面积。

## 工作记录

本例比较专色色块与纸面调子的不同表达，采用上下组合作为一项概念。织物染色、墨色、叶形和纸面内容都是设计选择。真实油墨、网线与材料组成另需相应证据。

预定全图观察：主次与完整性、纸边与图面共同几何、布面覆盖和纸面调子。纤维跨界、第二墨层独立表现与纸面细点按实际原生面积检查；关键处不足时保持待确认，并准备独立近景任务。实际图像质量尚待执行。
