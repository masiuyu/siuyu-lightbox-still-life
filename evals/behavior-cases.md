# 自然语言工作方式的行为案例

每个案例检查可观察的选择及产物。接口测试检查传递，以下判断还需实际执行者按请求与来源复核；涉及成图的案例在有对应图像授权后执行。

| 请求或条件 | 应有决定与证据 |
|---|---|
| 一张主体照片，要求光台研究。 | 从实际来源列出有限主体部件；采用乳白底光、对应研究、完整俯拍；方向自然语言可以解释这些关系。 |
| 仅提到描图纸或柔光箱。 | 继续默认底光透射，覆盖边界穿过真实笔迹，成图比较同一线条两侧。 |
| 用户明确选柔光纸层或印刷方向。 | 按指定目标选择相容载体、光与观察位置，直接写出已采用关系。 |
| 多件产品及几张风格参考。 | 每个产品有身份与保留内容，每个参考有明确用途，Image N 与文件顺序一致；全图逐件核对。 |
| 只有风格参考，要求新概念。 | 新主体按用户文字创作，参考承担指定摄影关系；创作选择与来源观察分别记录。 |
| 既有模型与来源照片。 | 原物模型保留自身外观，新建模型明确尺寸、工艺和辨识；二者采用正确身份。 |
| 用户确认布局，只改薄纸。 | 指定当前编辑目标，保留已确认布局与主体，只细化纸薄厚及光响应。 |
| 完整原图印在纸上。 | 核对完整窗口、数量、相对位置、天空与背景图形、裁切和遮挡；纸与图面共同变换。 |
| 纸面细点占很少像素。 | 判断观察条件不足，保持待确认，并规划适合的取景或独立细节任务。 |
| 织物双色印花。 | 说明底布、第一墨和第二墨；原生区域有可追踪纤维跨界及第二墨独立表现。 |
| 不透明织物与透光纸层同场。 | 分别安排反射与透射，材料和同一场景光路相容。 |
| 新上传与旧成图同时存在。 | 先看新来源，再按当前采用范围复核历史资料；接受依据来自用户表达。 |
| 只维护 Skill 或准备方向。 | 保存文件并执行适用检查，实际成像等待对应任务。 |
| 编译成功但成图有核心矛盾。 | 编译状态与视觉状态分别记录，评审需要修正，交付汇总与核心项一致。 |
| 核心项含未确认，用户尚未审阅。 | 总体待确认，用户接受单独保留待审阅。 |
| 用户要求严格源图面保留与精确网点。 | 在授权范围内选择实际支持的本地算法，保存参数和几何证据，再实际看图。 |
| 用户要求新建渲染器工程。 | 从自然语言目标进入明确工程任务，核对实际项目与运行时条件。 |

已有详细场景仍存于 evals.json，分别包含正常图像任务及配套工程协议案例。它们是验收素材；执行是否通过由对应实际证据决定。


## 案例方法的条件性应用

| 请求或条件 | 应有决定与证据 |
|---|---|
| 同一开口研究做横竖两图。 | 固定主体结构、图稿对应和纸层透射，横幅左右、竖幅上下重新分组；必要轮廓和纸角完整。对照 opening-study 两份方向。 |
| 比较同材质抛光与拉丝。 | 固定样片几何、尺度、朝向和共同光面，选能显出边界锐度与纹向的位置。实际表面效果等待成图。 |
| 大面积留白中的小对象无法辨认。 | 调整主体尺度、组间距或取景；根据任务安排近景。保留已经承担阅读或材料过渡作用的空区。 |
| 从卷尾孔洞发展新样片。 | 以穿孔解释基本单元，写清孔壁、后方底面与实际厚度；新样片按自己的身份成立。 |
| 同一系列包含不透明书布和半透明纸。 | 固定主体与研究关系，分别采用反射与透射所需光路，保留各自材料行为。 |
| 深色结构墨接近底布。 | 先观察与较亮第一墨相遇的位置，明确叠印和露布；颜色或分色改变记录为设计候选。 |
| 风格参考含强烈色调而产品要求保留原色。 | 选择保留原色与背景分离路径，参考影响落在允许的关系上。 |
| 只提供独立新生成的微观图片。 | 它证明本张模拟的可见关系；全图微观状态按全图自身的原生像素判断。 |
| 用户要求完整照片复制。 | 保留该图面完整窗口；其他全貌图或局部近景各承担自己的职责。 |

以上用于方向与评审判断，书面决定、实际图像、真实材料性能和用户接受分别验证。


## 局部关系的验证入口

| 请求或条件 | 应有决定与证据 |
|---|---|
| 让既有轮廓跨过纸孔边界。 | 先选原有线段，明确孔边两个交点，保留露出和覆盖两段；实际图中追踪接续及反差。局部处理保留主体、图稿和纸组。 |
| 第二墨与底布难分，定向处理仍未形成层序。 | 准备连续底墨块上的独立墨线小样，线两端位于底墨内部。小样成图按授权执行，先判断材料层序，再迁移到目标图形；原图状态分别保留。 |

## 材料、光与风格的跨题材判断

| 请求或条件 | 应有决定与证据 |
|---|---|
| 已涂蓝漆的金属盒，只改变表面光泽。 | 颜色、涂层覆盖和盒体结构保持；按漆面反射与细纹调整，真实加工方法另有依据。 |
| 深色木纹明显，但板面应平整。 | 分别说明纹路颜色、清漆反射与已有起伏，保持平整轮廓与实际纹向。 |
| 细缎面需要更细腻。 | 绑定处理区域、纹理尺度与反射过渡，检查曲率、轮廓和必要结构；全图与原生各承担相应尺度判断。 |
| 一张照片里出现宽白亮斑。 | 区分有效光面、反射方位、曝光和表面响应，先选择有证据的调整；粗糙度保持待确认范围。 |
| 织物采用较厚不透明覆盖。 | 按覆盖厚薄决定可保留的交织尺度，颜色覆盖与纱线起伏分别判断。 |
| 面光源较大，物件仍光滑。 | 分别检查反射边界和投影软硬，按相机、光面、表面与承影关系描述。 |
| 同场玻璃瓶和压纹纸需要不同线索。 | 给瓶边反射与纸面斜光分配主要任务，检查相互影响，保持共同光场与主体阅读。 |
| 亮膜图案被反射遮住。 | 优先调整光面与阅读区的位置，核对图案完整及表层光泽。 |
| 金属系列换成釉陶或玻璃。 | 保留选定的视点、主次和空间关系，为新材料分别落实反射或透射。 |
| 风格参考与产品识别色存在差异。 | 主体颜色依据当前要求，风格在允许的背景、辅助内容与光中实现。 |
| 新主体沿用旧图的器形或纹饰。 | 回查身份与参考用途，重新绑定当前主体特征，视觉状态按实际图记录。 |
| 一张新题材图符合方向。 | 记录该任务的适用证据与未检查条件；跨题材可靠性和用户接受继续按各自证据判断。 |

以上为行为验收案例。方法说明的情境演练、编译检查和真实图像测试分别保存，成图相关结论由实际图片决定。

## 创作关系与按需调用

| 请求或条件 | 应有决定与证据 |
|---|---|
| 普通光台研究请求。 | 主入口沿默认底光、完整俯拍与主体对应执行；仅选与实际难点相关的模块。 |
| 已确认画面，只改指定反光。 | 直接读取相关光路及摄影要求，保留身份与布局，编译后检查局部变化和保持项。 |
| 开放设计只给出气氛形容。 | 从当前对象找到具体特征，把它落实到大形、光影、材料或观看方式。 |
| 主体很小，辅助纹理吸引了全部注意。 | 先检查面积与对比、细节分配和空隙，再改对应构图；效果按全图判断。 |
| 选择长投影作为主要视觉动作。 | 投影方向、接触、承影面与实际光路相容，同时检查它与主体的视觉重量。 |
| 改变摄影机位。 | 复查可见结构、反射环境和背景透射，必要时返回材料、光与取景模块。 |
| 同一基本单元分别做玻璃器物与平面印色。 | 保留所选形状关系，分别使用体积透射或纸面墨层；各自记录身份和媒介效果。 |
| 静态任务的草稿含多个连续镜头动作。 | 选择需要的明确时刻；实际镜头规划另写起止状态与主要变化。 |
| 图像中要保留标签。 | 标签内容与载体明确，其他整体文字约束与其相容。 |
| 近景只放大原全图。 | 按已有原生像素判断；新的微观证据需要适合取景的实际图像。 |
| 文本方法与技术检查均完成。 | 记录文字与传递范围，成图效果与审美接受继续依实际证据判断。 |

## 成像关系与改动影响

| 请求或条件 | 应有决定与证据 |
|---|---|
| 台灯需要点亮，金属外壳仍需可读。 | 分开确定发光区域、受光桌面、外壳反射、遮挡和阅读区；实际检查原生图。 |
| 环向拉丝圆柱换一个机位。 | 纹向归属同一圆柱局部表面，新机位可改变画面方向、遮挡与反射；原有实体关系按来源保持。 |
| 产品颜色发白。 | 按可见位置区分反射、曝光色调和实际输出；有工程时再查色彩流程，单张外观保留原因不确定性。 |
| 两个镜头的相机位置不同。 | 保留实体布局和场景光的关系，重新描述各视角中的投影；真实连续性由实际序列判断。 |
| 暖调后暖白底墨与第二墨难分。 | 回查识别色、层次和关键区域；原生层序证据与处理效果分别记录。 |
| 腹部细缎面局部收细。 | 先看曲率、反射和原生纹理，复核轮廓、连接及既有纸层，沿用仍成立的构图。 |
| 艺术画面出现边缘融合。 | 对照本轮主张判断有意连接还是归属含混，按具体媒介调整间隙、遮挡或边缘处理。 |
| 图片中的黑白大色块符合创作目标。 | 判断需要的结构和材料是否可读，整体亮度及端点像素只提供相应证据。 |

## 实际图片证据与下一动作

| 请求或条件 | 应有决定与证据 |
|---|---|
| 多版本的调用、原生图和评审需要交接。 | 先实际确认版本，再可选建立对应收据；检查参数、文件状态与原生裁区。 |
| 文件核对通过，但材料层序仍有矛盾。 | 保留需要修正的视觉结论，下一动作针对层序及可见边界。 |
| 关键区域看不清。 | 保持待确认，按面积、焦点或反差改善观察条件；独立近景与全图分别判定。 |
| 原生裁区采用新的压缩方式。 | 按对应坐标比较像素，压缩方式与采样变化分别判断。 |
| 留存后替换了原图或改写评审。 | 按收据指出具体文件变化，新版本另行保存。 |
| 图片层序需要实物生产确认。 | 视觉评审记录实际边界与表面，真实层序按生产证据确认。 |

## 尺寸、材料成因与运动覆盖

| 请求或条件 | 应有决定与证据 |
|---|---|
| 矩形纸端正时放得下，转斜后靠近画框。 | 重新计算或观察旋转后的四角范围，合并全部物件位置并留出必要余量；同时核对画面两条轴。 |
| 同样输出尺寸中扩大完整工作台。 | 重查细节像素、主次与各物件受光，按任务重排或另设细节观察；通过实际图判断可读性。 |
| 人物照片用于彩绘模型及纸稿。 | 识别特征分别转成成品体块、涂装与纸上笔触；身份和材料各自评审，样片与当前用途对应。 |
| 木纹色差位于完整清漆下，局部另有磨穿。 | 各部位按颜色、反光、起伏及覆盖的实际成因描述；磨穿边界与底材在同一位置成立。 |
| 模型表面局部改细腻，旁边样片研究同一种成品表面。 | 复查样片纹理尺度和光响应的对应；图稿、徽章按各自媒介表达身份。 |
| 镜头首尾完整，中途沿弧线向边缘移动。 | 检查途中最大偏移和遮挡，必要物件及文字沿路径可用；真实连续性由实际视频验证。 |
| 白色光台及精细织物需要视频交付。 | 保留当前视觉目标，在实际编码及观看尺寸下复核细纹、亮暗和文字，按具体问题选择处理。 |

## 可选取景计算

| 请求或条件 | 应有决定与证据 |
|---|---|
| 有尺寸资料或设计假设，需要反复比较纸张转角与画幅。 | 可选运行 framing，将当前单位、尺寸依据、位置与输出像素写入独立计算计划；最后的画面继续用自然语言表达。 |
| 输入视场比例与输出图像不同。 | 报告以相同原点扩展视场到输出比例，按统一比例尺分配细节像素；实际图片另行观察。 |
| 当前矩形在视场内，但未达到所需余量。 | 分别记录 inside_view 与 planned_margin_met，按具体短缺选择重排、转角或视场。 |
| 计算给出少于一个像素的跨度。 | 记录采样分配，结合反差、方向和实际图判断，按本轮任务选择合适观察条件。 |
| 计划自称尺寸来自实测。 | 保留依据声明，程序核验状态仍为未评估；真实尺寸依据由对应资料支持。 |

## 视觉语言与研究媒介

这些案例检查创作决定；实际视觉差异按对应成图评审。

| 请求或条件 | 应有决定与证据 |
|---|---|
| 为一枚开口圆环做不同桌面设计研究，材料与稿件媒介开放。先交文字方向。 | 按不同观看问题发展方向，如线材转弯、反射曲率与压印成型。各自选择研究媒介、材料构造、空间、边缘和光，说明相互作用。数量按任务需要；本轮交付书面决定，效果待实际图片。 |
| 产品材质和颜色保持原图，周围研究稿和构图大胆变化。 | 原物身份、材质和颜色按来源锁定；研究媒介、光影、背景及空间在开放范围发展。材料可以形成研究图形，各物明确归属与对应。实际检查锁定项与选定变化。 |
| 参考这些手机截图里的视觉方法，创作我的新主题。 | 逐图定位有效作品窗口，描述可见机制及本轮用途。参考中的界面与讲解属于来源上下文。新图以当前主题与载体组织形体、光色和空间，标题只帮助定位。 |
| 金属成品保持真实，旁边研究图用扫描拉伸和伪彩。 | 金属按实体形状与反射实现；扫描拉伸和伪彩附着在指定研究图面，明确保持的识别锚点、允许变化区域及载体。分别检查实体、介质与图面。 |
| 做一张线材形成符号的织物研究，给我选择做法。 | 按目的选择针织、刺绣、粗绳固定或镂空等构造，说明底材、线径、针脚、交叠、转弯与收边；光显示相应厚度与阴影。具体纤维及制造信息依据资料或本轮设计。 |
| 四个对象都用暗底：金属马、玻璃杯、哑光果实和剪影。 | 为各对象分别安排反射亮暗形状、透明厚边和透射、漫反射渐变、前后亮区对照，保留各自必要身份。暗底作为共同关系，实际光路按材料与任务求解。 |
| 隔着有水滴的雾面片看产品，留一个清楚部位。 | 明确界面与主体前后关系，前层水滴边缘、界面散射、后方离焦及识别窗口各有范围；支撑与接触成立。按实际清晰度和可见身份检查。 |
| 研究同一图形的蜡印正负形。 | 选定压印完成或过程时刻，说明印头与蜡负形的对应、厚薄、挤出边缘和支撑。侧光及填影让凹凸可读，制造性能与实际温度由资料另行确认。 |
| 用木材做图形研究，木纹和图形要有联系。 | 先选纹向、板面端面及拼接，再选择印色、凹刻、凸起或嵌入，按所选工艺安排边缘、起伏和光。平整纹路色差与刻痕深浅分别判断，实际木种依据资料。 |
| 做微观与透视内部的艺术研究稿。 | 明确艺术概念与有据结构，选择孔隙、网、切片或选择性显露作为图面语言，载体与实体各有规则。真实内部、倍率及测量信息需要对应记录。 |
| 检查这些不同主题的桌面方案是否有实质差异。 | 对照各自观看目标，隐藏题材与风格标题比较大形、密度、媒介形成方式、边缘、空间及光影。将已落实的设计区别与待成图验证分别记录；依实际反馈判断需要改变的关系。 |
